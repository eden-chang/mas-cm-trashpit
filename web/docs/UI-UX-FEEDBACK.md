# 웹 UI/UX 피드백 및 개선 제안

시니어 UI/UX·프론트엔드 관점에서 현재 TRASHPIT 웹 UI를 검토한 결과입니다.

---

## 잘 되어 있는 점

- **정보 구조**: 메인(인벤토리) + 우측 캐릭터 패널 구조가 명확함.
- **반응형**: 모바일에서 사이드바 드로어, 그리드 셀 크기(36px/48px) 터치 고려.
- **시맨틱/접근성**: `role`, `aria-label`, `aria-valuenow` 등 기본 접근성 마크업 적용.
- **테마**: KoPub Dotum, 다크 테마, CSS 변수로 색/반경 일관성 유지.
- **상태 피드백**: 로딩/에러/저장 중/미저장 변경 표시가 있음.
- **드래그 앤 드롭**: 그리드·Nearby·Misc·Trash 드롭 타겟 구분, 유효/무효 드롭 시각 피드백(파랑/초록/빨강).

---

## 개선이 필요한 부분

### 1. 레이아웃·기능 누락

- **TrashZone 미노출**: `BagTab.tsx`에 TrashZone 컴포넌트와 `handleTrashDrop`이 구현되어 있으나 **화면에 렌더되지 않음**. 사용자가 아이템을 “버리기” 위해 드롭할 영역이 없음.
  - **제안**: MISC / Nearby 아래 또는 그리드 하단에 “버리기” 영역(TrashZone)을 추가해 드롭으로 삭제 가능하게 할 것.

### 2. 글로벌 스타일·클래스

- **index.html**: `body`에 `bg-bg-base` 사용. `theme.css`에는 `--bg-base`가 없고 `--background`(→ `--bg`)만 정의됨. Tailwind v4에서 `bg-background` 또는 `bg-[var(--bg)]` 사용이 맞음.
  - **제안**: `bg-bg-base` → `bg-background` 또는 `bg-[var(--bg)]`로 수정.

### 3. 빈 상태(Empty State)

- MISC SPACE / NEARBY의 “무게 없는 아이템 없음”, “주변 아이템 없음” 문구가 기능 설명 없이 짧음.
  - **제안**: 한 줄 설명 추가 (예: “가방이나 주변에서 끌어다 놓으면 여기로 옮겨져요”)로 기대 행동을 안내.

### 4. 다이얼로그 UX

- **수량 선택 다이얼로그** (BagTab 내 인라인 구현):
  - ESC로 닫기 미지원.
  - 열릴 때 첫 포커스(취소/확인 또는 수량 입력)로 가두는 포커스 트랩 없음.
  - 배경 클릭 시 닫기 없음 (의도적일 수 있으나, 모달이라면 ESC + 포커스 트랩은 권장).
  - **제안**: `useEffect`로 열릴 때 포커스 이동, `onKeyDown`으로 ESC 시 `onClose`, 필요 시 `focus-trap` 라이브러리 또는 직접 ref 관리.

### 5. 시각적 위계·가독성

- 섹션 제목(INVENTORY BAG, MISC SPACE, NEARBY ITEMS)이 모두 `uppercase` + `tracking-wider`로 비슷해, “가방”이 메인인지 한눈에 구분이 약함.
  - **제안**: Inventory Bag만 크기/굵기 강화(예: `text-base` + `font-bold`)하고, 나머지는 `text-xs` 유지해 위계 차이 두기.
- 캐릭터 카드 내 HP/BAG 프로그레스 바가 `h-1.5`로 작음. 모바일에서 터치 타겟은 버튼만 있고 바 자체는 정보용이므로, 데스크톱에서만 `h-2` 등으로 약간 키우면 가독성 향상.

### 6. 컴포넌트 중복·유지보수

- 수량 선택 UI가 `BagTab.tsx` 안에 인라인으로 약 80줄 있고, `QuantityDialog.tsx`도 동일한 역할로 존재. 상태 형태만 약간 다름.
  - **제안**: 한 곳으로 통일. BagTab은 `QuantityDialog` 상태만 넘기고, QuantityDialog 컴포넌트를 재사용하면 스타일/접근성 수정을 한 곳에서 할 수 있음.

### 7. 타이머·데이터

- `timeRemaining`이 App에서 `31522`로 하드코딩되어 있음. 실제 “Nearby 삭제까지 남은 시간”이라면 API/캐릭터 데이터에서 내려받는 것이 맞음.
  - **제안**: API 또는 전역 상태에서 남은 시간을 받아 표시하거나, 임시라면 “데모: 8:45 남음” 등 라벨로 명시.

### 8. 버튼 순서·강조

- 사이드바 하단: “클라우드 동기화” → “저장되지 않은 변경사항” → “데이터 새로고침”. 주 액션(동기화)이 위에 있어 적절함. 변경사항이 있을 때만 표시되는 경고 블록도 위치가 무난함.

### 9. 그리드·드래그

- 5칸 단위 굵은 선, 셀 호버/드롭 시 색상 피드백이 있어 그리드 인지에 도움이 됨. 모바일에서는 HTML5 Backend만으로 드래그가 불편할 수 있음.
  - **제안**: 추후 터치 전용 제스처(롱프레스 후 드래그) 또는 “길게 눌러 이동” 안내 툴팁을 검토.

### 10. 에러·재시도

- 캐릭터 로딩 실패 시 “다시 시도” 버튼이 있어 좋음. 저장 실패 메시지는 사이드바 하단에 표시되나, 스크롤 시 안 보일 수 있음.
  - **제안**: 저장 실패 시 토스트(sonner 등)로 짧게 띄우고, 사이드바 메시지는 보조로 두면 재시도 가능성과 가시성이 모두 좋아짐.

## 적용한/권장 개선 요약

| 우선순위 | 항목 | 조치 | 상태 |
|---------|------|------|------|
| 높음 | TrashZone 미노출 | 레이아웃에 TrashZone 추가 | ✅ 적용 |
| 높음 | body 배경 클래스 | `bg-bg-base` → `bg-background` | ✅ 적용 |
| 중간 | 수량 다이얼로그 | ESC 닫기, 포커스 트랩(또는 첫 포커스 이동) | ✅ 적용 |
| 중간 | 빈 상태 문구 | MISC/Nearby에 짧은 안내 문구 추가 | ✅ 적용 |
| 낮음 | 섹션 제목 위계 | Inventory Bag 시각적 강조 | ✅ 적용 |
| 낮음 | 다이얼로그 통합 | QuantityDialog 컴포넌트로 인라인 대체 | ✅ 적용 |
| 낮음 | 타이머 데모 라벨 | `timerLabel="데모"` prop, Nearby에 "데모 · HH:MM:SS 후 삭제" 표시 | ✅ 적용 |
| 낮음 | 저장 실패 토스트 | sonner `toast.error` + `<Toaster theme="dark" />` | ✅ 적용 |

위 항목 중 즉시 적용 가능한 것부터 코드에 반영하겠습니다.
