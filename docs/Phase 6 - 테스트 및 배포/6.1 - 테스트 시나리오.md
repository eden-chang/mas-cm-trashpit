## 봇–Supabase 연결성 테스트 전제 조건

`tests/test_bot_supabase_connection.py` 는 각 봇 명령(획득/버리기/사용/양도 아이템·포인트/지급) 실행 후 **Supabase에 기대한 대로 반영되는지** 검증합니다. 다음 환경 변수와 데이터가 필요합니다.

| 환경 변수 | 필수 | 설명 |
|-----------|------|------|
| `ENABLE_BOT_SUPABASE_TESTS` | 예 | `true` 로 설정해야 봇–Supabase 테스트 실행 (미설정 시 전체 스킵) |
| `TEST_CHARACTER` | 예 | 테스트용 캐릭터 **이름** (Supabase `characters.name` 에 존재) |
| `TEST_MASTODON_ID` | 예 | 해당 캐릭터의 마스토돈 계정 ID (`characters.id` 컬럼 값) |
| `TEST_ITEM` | 예 | 테스트용 아이템명 (Supabase `items` 테이블에 존재) |
| `TEST_CHARACTER_RECEIVER` | 선택 | 양도(아이템/포인트) 수신자 캐릭터 이름 (미설정 시 양도 관련 테스트 스킵) |

**데이터 전제**

- Supabase `characters` 테이블에 `name = TEST_CHARACTER`, `id = TEST_MASTODON_ID` 인 행이 있어야 함.
- Supabase `items` 테이블에 `name = TEST_ITEM` 인 행이 있어야 함.
- 양도(포인트) 테스트를 실행하려면 `TEST_CHARACTER` 의 `points` 가 1 이상이어야 함 (부족 시 해당 테스트만 스킵).

**실행 예**

```bash
# 봇–Supabase 테스트만 실행 (전제 조건 충족 시)
ENABLE_BOT_SUPABASE_TESTS=true TEST_CHARACTER=데이릭\ 워드 TEST_MASTODON_ID=song.pyeon TEST_ITEM=사과 python -m pytest tests/test_bot_supabase_connection.py -v

# 수신자까지 지정해 양도 테스트 포함
ENABLE_BOT_SUPABASE_TESTS=true TEST_CHARACTER=... TEST_MASTODON_ID=... TEST_ITEM=... TEST_CHARACTER_RECEIVER=총괄 python -m pytest tests/test_bot_supabase_connection.py -v
```

## 명령어 테스트

### [사용/아이템명]

| 케이스 | 입력 | 예상 결과 |
|--------|------|----------|
| 정상 사용 | `[사용/사과]` | 체력 +3, 사과 -1, 사용문구 출력 |
| 마지막 아이템 | `[사용/사과]` (1개 남음) | 체력 +3, "마지막 사과" 메시지 |
| 미소지 | `[사용/물약]` | "소지하고 있지 않습니다" |
| 사용 불가 | `[사용/칼]` | "사용할 수 없는 아이템" |
| 존재하지 않는 아이템 | `[사용/???]` | "존재하지 않는 아이템" |

### [획득/아이템명]

| 케이스 | 입력 | 예상 결과 |
|--------|------|----------|
| 정상 획득 | `[획득/사과]` | 주변에 사과 추가 |
| 부피 0 아이템 | `[획득/클립]` | 여유공간에 추가 |
| 가방 꽉 참 | `[획득/의료키트]` (공간 부족) | 주변에 추가 + 경고 |

### [버리기/아이템명]

| 케이스 | 입력 | 예상 결과 |
|--------|------|----------|
| 주변에서 버리기 | `[버리기/사과]` | 주변에서 삭제 |
| 가방에서 버리기 | `[버리기/물병]` | 가방에서 삭제 |
| 미소지 | `[버리기/???]` | "소지하고 있지 않습니다" |

### [양도/아이템명/이름]

| 케이스 | 입력 | 예상 결과 |
|--------|------|----------|
| 정상 양도 | `[양도/사과/엘리사]` | 발신자에서 삭제, 수신자 주변에 추가 |
| 부피 0 양도 | `[양도/클립/엘리사]` | 수신자 여유공간에 추가 |
| 자기 자신 | `[양도/사과/발트]` | "자기 자신에게는 양도할 수 없습니다" |
| 미소지 | `[양도/???/엘리사]` | "소지하고 있지 않습니다" |
| 수신자 없음 | `[양도/사과/???]` | "캐릭터를 찾을 수 없습니다" |

### [양도/n포인트/이름]

| 케이스 | 입력 | 예상 결과 |
|--------|------|----------|
| 정상 양도 | `[양도/100포인트/엘리사]` | 포인트 이동, 양쪽 알림 |
| 포인트 부족 | `[양도/1000포인트/엘리사]` | "포인트가 부족합니다" |
| 0 이하 | `[양도/0포인트/엘리사]` | "1 이상이어야 합니다" |

## 웹 테스트

### 가방 정리

| 케이스 | 액션 | 예상 결과 |
|--------|------|----------|
| 주변 → 가방 | 드래그앤드롭 | 가방에 추가, 주변에서 삭제 |
| 공간 부족 | 큰 아이템 드롭 | "공간 부족" 메시지, 이동 안 됨 |
| 저장 | 저장 버튼 | 시트 업데이트, 성공 메시지 |
| 용량 초과 저장 | 21/20으로 저장 | "용량 초과" 에러 |

### 아이템 버리기

| 케이스 | 액션 | 예상 결과 |
|--------|------|----------|
| 휴지통으로 드래그 | 아이템 드래그 | 확인 대화상자 |
| 확인 | "확인" 클릭 | 아이템 삭제 |
| 취소 | "취소" 클릭 | 원위치 |

## 자동화 테스트

### 주변 아이템 자동 삭제

| 케이스 | 조건 | 예상 결과 |
|--------|------|----------|
| 아이템 있음 | 주변에 아이템 | 삭제 + 알림 |
| 아이템 없음 | 주변 비어있음 | 아무 동작 없음 |
| 경고 알림 | 23시 | 삭제 예정 알림 |

### 실시간 동기화

| 케이스 | 조건 | 예상 결과 |
|--------|------|----------|
| 외부 변경 | 봇에서 아이템 사용 | 웹에 반영 |
| 충돌 | 동시 편집 | 경고 메시지 |

## 테스트 코드 예시

```python
import unittest

class TestCommands(unittest.TestCase):

    def setUp(self):
        # 테스트 데이터 초기화
        self.test_char = '테스트캐릭터'
        update_cell(self.test_char, '가방', '사과:3')
        update_cell(self.test_char, '주변', '')
        update_cell(self.test_char, '체력', 50)

    def test_use_item_success(self):
        """[사용] 정상 케이스"""
        result = handle_use_test(self.test_char, '사과')

        self.assertTrue(result['success'])
        self.assertEqual(result['remaining'], 2)

        char = get_character_by_name(self.test_char)
        self.assertEqual(char['체력'], 53)  # +3

    def test_use_item_not_found(self):
        """[사용] 미소지"""
        result = handle_use_test(self.test_char, '물약')

        self.assertFalse(result['success'])
        self.assertIn('소지하고 있지 않습니다', result['error'])

    def test_give_item_success(self):
        """[양도] 정상 케이스"""
        result = handle_give_test(self.test_char, '사과', '수신캐릭터')

        self.assertTrue(result['success'])

        sender = get_character_by_name(self.test_char)
        receiver = get_character_by_name('수신캐릭터')

        self.assertNotIn('사과', sender['가방'])
        self.assertIn('사과', receiver['주변'])

    def tearDown(self):
        # 테스트 데이터 정리
        pass

if __name__ == '__main__':
    unittest.main()
```
