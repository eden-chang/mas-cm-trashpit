# 6.2 - 배포 가이드

## 개요

봇과 웹 서비스를 배포하는 방법을 설명합니다.

---

## 필수 요구사항

- Python 3.10+
- Node.js 18+ (웹 빌드 시)
- Supabase 프로젝트 (PostgreSQL)
- 마스토돈 봇 계정 및 액세스 토큰

---

## 환경 설정

### 1. 저장소 클론

```bash
git clone <repository-url>
cd trashpit
```

### 2. 가상환경 생성

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 또는
venv\Scripts\activate  # Windows
```

### 3. 의존성 설치

```bash
pip install -r requirements.txt
```

### 4. 환경 변수 설정

`.env` 파일 생성:

```env
# Supabase
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=your_service_role_key

# Mastodon
MASTODON_API_BASE_URL=https://trashpit.site
BOT_ACCESS_TOKEN=your_token_here
SYSTEM_ADMIN_ID=longwhile,TP_Mst
POLLING_INTERVAL=30

# API
FLASK_DEBUG=False
API_HOST=0.0.0.0
API_PORT=5000
CORS_ORIGINS=*

# 캐시
CACHE_TTL=60
CACHE_TTL_ITEMS=300
CACHE_TTL_CHARACTERS=30
```

## 서버 배포

### systemd 서비스 (Linux)

`/etc/systemd/system/trashpit-bot.service`:

```ini
[Unit]
Description=Trashpit Mastodon Bot
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/home/deploy/trashpit
Environment=PATH=/home/deploy/trashpit/venv/bin
ExecStart=/home/deploy/trashpit/venv/bin/python -m bot.main
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable trashpit-bot
sudo systemctl start trashpit-bot
sudo systemctl status trashpit-bot
```

### API 서버 (gunicorn + nginx)

`/etc/systemd/system/trashpit-api.service`:

```ini
[Unit]
Description=Trashpit API Server
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/home/deploy/trashpit
Environment=PATH=/home/deploy/trashpit/venv/bin
ExecStart=/home/deploy/trashpit/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 api.app:app
Restart=always

[Install]
WantedBy=multi-user.target
```

nginx 설정:

```nginx
server {
    listen 80;
    server_name inventory.trashpit.site;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /static {
        alias /home/deploy/trashpit/web/dist;
    }
}
```

## Docker 배포 (선택)

### Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "-m", "bot.main"]
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  bot:
    build: .
    env_file: .env
    restart: unless-stopped

  api:
    build: .
    command: gunicorn -w 4 -b 0.0.0.0:5000 api.app:app
    env_file: .env
    ports:
      - "5000:5000"
    restart: unless-stopped
```

```bash
docker-compose up -d
```

## 트러블슈팅

### Supabase 연결 오류

```
postgrest.exceptions.APIError: connection refused
```

- `SUPABASE_URL` 확인
- `SUPABASE_SERVICE_KEY` 유효성 확인 (Service Role 키 사용)
- 네트워크/방화벽 설정 확인

### 마스토돈 연결 오류

```
mastodon.errors.MastodonUnauthorizedError
```

- `BOT_ACCESS_TOKEN` 유효성 확인
- `MASTODON_API_BASE_URL` 확인

### 캐시 관련 이슈

```
데이터가 즉시 반영되지 않음
```

- `CACHE_TTL_CHARACTERS` 값 확인 (기본 30초)
- 필요시 수동 캐시 무효화 호출

### 메모리 부족

```
MemoryError
```

- 캐시 TTL 줄이기
- 서버 메모리 증설
