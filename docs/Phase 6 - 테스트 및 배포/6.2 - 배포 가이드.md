## 서버 배포

### systemd 서비스 (Linux)

`/etc/systemd/system/trashpit-bot.service`:

```ini
[Unit]
Description=Trashpit Mastodon Bot
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/home/deploy/trashpit
Environment=PATH=/home/deploy/trashpit/venv/bin
ExecStart=/home/deploy/trashpit/venv/bin/python bot/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable trashpit-bot
sudo systemctl start trashpit-bot
sudo systemctl status trashpit-bot
```

### 웹 서버 (gunicorn + nginx)

`/etc/systemd/system/trashpit-web.service`:

```ini
[Unit]
Description=Trashpit Web Server
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/home/deploy/trashpit
Environment=PATH=/home/deploy/trashpit/venv/bin
ExecStart=/home/deploy/trashpit/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 web.app:app
Restart=always

[Install]
WantedBy=multi-user.target
```

nginx 설정:

```nginx
server {
    listen 80;
    server_name inventory.trashpit.site;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /static {
        alias /home/deploy/trashpit/web/static;
    }
}
```

## Docker 배포 (선택)

### Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "bot/main.py"]
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  bot:
    build: .
    env_file: .env
    volumes:
      - ./credentials.json:/app/credentials.json:ro
    restart: unless-stopped

  web:
    build: .
    command: gunicorn -w 4 -b 0.0.0.0:5000 web.app:app
    env_file: .env
    ports:
      - "5000:5000"
    volumes:
      - ./credentials.json:/app/credentials.json:ro
    restart: unless-stopped
```

```bash
docker-compose up -d
```

## 트러블슈팅

### 구글 시트 API 오류

```
gspread.exceptions.APIError: 403 Forbidden
```

- 서비스 계정 이메일에 시트 공유 권한 확인
- credentials.json 경로 확인

### 마스토돈 연결 오류

```
mastodon.errors.MastodonUnauthorizedError
```

- BOT_ACCESS_TOKEN 유효성 확인
- API_BASE_URL 확인

### 메모리 부족

```
MemoryError
```

- 캐시 TTL 줄이기
- 서버 메모리 증설
