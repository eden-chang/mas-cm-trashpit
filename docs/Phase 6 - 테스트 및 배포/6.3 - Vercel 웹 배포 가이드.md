# 6.3 - Vercel 웹 배포 가이드

`web` 폴더의 Vite + React 웹앱을 Vercel로 발행하는 단계별 가이드입니다.

---

## 사전 준비

- [GitHub](https://github.com) / [GitLab](https://gitlab.com) / [Bitbucket](https://bitbucket.org)에 프로젝트가 푸시되어 있어야 합니다.
- [Vercel](https://vercel.com) 계정 (GitHub 등으로 가입 가능).

---

## 1단계: Vercel 가입 및 프로젝트 가져오기

1. **https://vercel.com** 접속 후 **Sign Up** 또는 **Log In**.
2. **Add New…** → **Project** 선택.
3. **Import Git Repository**에서 사용 중인 저장소(예: GitHub)를 연결한 뒤, `trashpit`(또는 해당 저장소)를 선택하고 **Import** 클릭.

---

## 2단계: 빌드 설정 (Root Directory 필수)

이 저장소는 **루트가 Python/봇**이고, 웹앱은 **`web`** 폴더에 있으므로 **Root Directory**를 반드시 지정해야 합니다.

1. **Configure Project** 화면에서:
   - **Root Directory**: **Edit** 클릭 → `web` 입력 후 **Continue**.
2. **Framework Preset**: **Vite**가 자동 감지되면 그대로 두고, 아니면 **Vite** 선택.
3. **Build and Output Settings** (필요 시 **Override** 체크):
   - **Build Command**: `npm run build` (기본값 유지)
   - **Output Directory**: `dist` (Vite 기본값)
   - **Install Command**: `npm install` (기본값 유지)

4. **Deploy** 클릭.

---

## 3단계: 환경 변수 (필수 — API 연동 시)

- Vercel에 올린 웹은 **정적 사이트**이므로 같은 도메인에는 `/api`가 없습니다. **캐릭터/가방 API**를 쓰려면 반드시 아래를 설정해야 합니다.
- **Settings** → **Environment Variables**에서 추가:
  - **이름:** `VITE_API_BASE_URL`
  - **값:** API 서버 **전체 주소(프로토콜 포함, 끝에 슬래시 없음)**  
    예: `https://your-api.vercel.app`, `https://api.trashpit.site`
- Vite는 `VITE_` 접두사 변수만 빌드 시 클라이언트에 포함하므로, 이름을 `VITE_API_BASE_URL`로 두어야 합니다.
- 값을 바꾼 뒤에는 **재배포(Redeploy)** 해야 반영됩니다.

---

## 4단계: 배포 확인

1. 배포가 끝나면 **Visit** 링크로 사이트 접속.
2. SPA 라우팅(예: `/bag`, `/free` 등)으로 직접 이동해도 404가 나지 않고 `index.html`이 서빙되는지 확인.
   - `web/vercel.json`에 `rewrites`가 설정되어 있어 이 동작이 가능합니다.

---

## 5단계: 커스텀 도메인 (선택)

1. Vercel 대시보드에서 프로젝트 선택 → **Settings** → **Domains**.
2. **Add**로 도메인 입력 후, DNS에 안내된 CNAME/ A 레코드 설정.

---

## CLI로 배포하는 방법

터미널에서 직접 배포하려면:

```bash
# Vercel CLI 설치 (최초 1회)
npm i -g vercel

# web 폴더로 이동 후 로그인 및 배포
cd web
vercel
```

최초 실행 시 로그인과 프로젝트 연결을 묻습니다. **Set up and deploy?** 에서 **Y** 선택 후, Root Directory 질문이 나오면 **current directory**를 선택하면 됩니다.

이후 배포만 반복할 때:

```bash
cd web
vercel --prod
```

`--prod`는 프로덕션 도메인에 배포합니다.

---

## 트러블슈팅

| 증상 | 확인 사항 |
|------|-----------|
| 빌드 실패 (Module not found 등) | Root Directory가 `web`으로 설정되었는지 확인. |
| 404 on refresh / 직접 URL 접속 | `web/vercel.json`의 `rewrites`가 있는지, Root가 `web`인지 확인. |
| API 호출 실패 | 프로덕션 API URL을 환경 변수(`VITE_*`)로 설정했는지, CORS가 허용되는지 확인. |
