# 3.3 - 캐싱 및 성능

## 개요

Supabase API 호출을 줄이기 위한 캐싱 전략을 구현합니다.

---

## 캐싱 정책

| 데이터 | 캐싱 | TTL | 이유 |
|--------|------|-----|------|
| **characters** | ✅ 적용 | 30초 | 실시간 인벤토리 변동, 짧은 TTL |
| **items** | ✅ 적용 | 300초 | 아이템 마스터는 자주 변경되지 않음 |

**중요**: 데이터 변경 시 반드시 캐시를 무효화해야 합니다.

---

## 문제점

- Supabase API 호출 비용
- 매 요청마다 DB 조회 시 지연
- 동시 접속 시 성능 저하

## 메모리 캐시

### 단순 캐시

```python
import time
from functools import wraps

CACHE_TTL = int(os.getenv('CACHE_TTL', 60))
CACHE_TTL_ITEMS = int(os.getenv('CACHE_TTL_ITEMS', 300))
CACHE_TTL_CHARACTERS = int(os.getenv('CACHE_TTL_CHARACTERS', 30))

_cache = {}

def cached(ttl=CACHE_TTL):
    """TTL 기반 캐시 데코레이터"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            key = f"{func.__name__}:{args}:{kwargs}"

            if key in _cache:
                value, timestamp = _cache[key]
                if time.time() - timestamp < ttl:
                    return value

            result = func(*args, **kwargs)
            _cache[key] = (result, time.time())
            return result

        return wrapper
    return decorator

def invalidate_cache(pattern=None):
    """캐시 무효화"""
    global _cache
    if pattern:
        _cache = {k: v for k, v in _cache.items() if pattern not in k}
    else:
        _cache = {}
```

## 캐시 무효화

데이터 변경 시 관련 캐시를 무효화합니다.

```python
def invalidate_character_cache(name: str):
    """캐릭터 관련 캐시 무효화"""
    invalidate_cache(f"get_character_by_name:('{name}'")
    invalidate_cache(f"get_all_characters")

def update_bag_items(name: str, items: dict) -> bool:
    """가방 아이템 업데이트 + 캐시 무효화"""
    supabase = get_supabase()
    response = (
        supabase.table(TABLE_CHARACTERS)
        .update({"bag": items})
        .eq("name", name)
        .execute()
    )
    if response.data:
        invalidate_character_cache(name)
        return True
    return False
```

## Redis 캐시 (선택)

대규모 운영 시 Redis를 사용할 수 있습니다.

```python
import redis
import json

redis_client = redis.Redis(host='localhost', port=6379, db=0)

def redis_cached(ttl=CACHE_TTL):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            key = f"inv:{func.__name__}:{args}:{kwargs}"

            cached = redis_client.get(key)
            if cached:
                return json.loads(cached)

            result = func(*args, **kwargs)
            redis_client.setex(key, ttl, json.dumps(result))
            return result

        return wrapper
    return decorator

def redis_invalidate(pattern: str):
    """패턴 매칭 캐시 삭제"""
    for key in redis_client.scan_iter(f"inv:*{pattern}*"):
        redis_client.delete(key)
```

## 배치 읽기

여러 데이터를 한 번에 읽어 API 호출을 줄입니다.

```python
def preload_all_data():
    """모든 데이터를 한 번에 로드"""
    global _cache

    supabase = get_supabase()
    
    # 캐릭터 전체 로드
    response = supabase.table(TABLE_CHARACTERS).select("*").execute()
    for row in response.data:
        char = _row_to_character(row)
        key = f"get_character_by_name:('{char.name}')"
        _cache[key] = (char, time.time())

    # 아이템 전체 로드
    response = supabase.table(TABLE_ITEMS).select("*").execute()
    for row in response.data:
        try:
            info = _row_to_item_info(row)
            key = f"get_item_info:('{info.name}')"
            _cache[key] = (info, time.time())
        except ValueError:
            continue

# 시작 시 호출
preload_all_data()
```
