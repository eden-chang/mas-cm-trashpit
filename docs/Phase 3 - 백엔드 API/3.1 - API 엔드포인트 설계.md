# 3.1 - API 엔드포인트 설계

## 개요

웹 인터페이스와 봇이 사용하는 REST API 엔드포인트를 정의합니다.

---

## 엔드포인트 목록

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/api/character/<name>` | 캐릭터 전체 정보 |
| GET | `/api/bag/<name>` | 가방 아이템 조회 |
| POST | `/api/bag/<name>` | 가방 아이템 업데이트 |
| GET | `/api/nearby/<name>` | 주변 아이템 조회 |
| POST | `/api/nearby/<name>/move` | 주변 → 가방 이동 |
| GET | `/api/items` | 전체 아이템 목록 |
| GET | `/api/item/<name>` | 아이템 정보 조회 |

---

## 캐릭터 정보

### GET `/api/character/<name>`

캐릭터의 전체 정보를 반환합니다.

**Response:**
```json
{
  "name": "발트",
  "mastodon_id": "balt",
  "health": 50,
  "strength": 5,
  "luck": 3,
  "bag_capacity": 20,
  "bag_used": 10,
  "bag_items": [
    {"name": "사과", "quantity": 3, "volume": 1},
    {"name": "물병", "quantity": 2, "volume": 2}
  ],
  "misc_items": [
    {"name": "클립", "quantity": 2},
    {"name": "동전", "quantity": 5}
  ],
  "nearby_items": [
    {"name": "의료키트", "quantity": 1, "volume": 5}
  ]
}
```

---

## 가방 관리

### GET `/api/bag/<name>`

가방 아이템과 용량 정보를 반환합니다.

**Response:**
```json
{
  "capacity": 20,
  "used": 10,
  "available": 10,
  "items": [
    {"name": "사과", "quantity": 3, "volume": 1, "total_volume": 3},
    {"name": "물병", "quantity": 2, "volume": 2, "total_volume": 4}
  ]
}
```

### POST `/api/bag/<name>`

가방 아이템을 업데이트합니다 (웹에서 저장 시).

**Request:**
```json
{
  "items": [
    {"name": "사과", "quantity": 2},
    {"name": "물병", "quantity": 3}
  ]
}
```

**Response (성공):**
```json
{
  "success": true,
  "used": 12,
  "available": 8
}
```

**Response (실패):**
```json
{
  "success": false,
  "error": "용량 초과 (22/20)"
}
```

---

## 주변 → 가방 이동

### POST `/api/nearby/<name>/move`

주변 아이템을 가방으로 이동합니다.

**Request:**
```json
{
  "item_name": "의료키트",
  "quantity": 1
}
```

**Response (성공):**
```json
{
  "success": true,
  "message": "의료키트를 가방에 넣었습니다."
}
```

**Response (공간 부족):**
```json
{
  "success": false,
  "error": "가방 공간이 부족합니다. (필요: 5, 남음: 3)"
}
```

## Flask 구현

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/character/<name>')
def get_character(name):
    char = get_character_by_name(name)
    if not char:
        return jsonify({'error': '캐릭터를 찾을 수 없습니다.'}), 404

    capacity = calculate_capacity(char['근력'])
    bag_items = parse_inventory(char['가방'])
    used = calculate_used_volume(char['가방'])

    return jsonify({
        'name': char['이름'],
        'mastodon_id': char['아이디'],
        'health': char['체력'],
        'strength': char['근력'],
        'luck': char['행운'],
        'bag_capacity': capacity,
        'bag_used': used,
        'bag_items': enrich_items(bag_items),
        'misc_items': parse_inventory(char['여유공간']),
        'nearby_items': enrich_items(parse_inventory(char['주변']))
    })

@app.route('/api/bag/<name>', methods=['POST'])
def update_bag(name):
    items = request.json.get('items', [])

    # 용량 검증
    total_volume = sum(
        get_item_info(item['name'])['volume'] * item['quantity']
        for item in items
    )

    capacity = calculate_capacity(get_character_by_name(name)['근력'])

    if total_volume > capacity:
        return jsonify({
            'success': False,
            'error': f'용량 초과 ({total_volume}/{capacity})'
        }), 400

    # 시트 업데이트
    update_bag_items(name, items)

    return jsonify({
        'success': True,
        'used': total_volume,
        'available': capacity - total_volume
    })

def enrich_items(items):
    """아이템에 부피 정보 추가"""
    result = []
    for item in items:
        info = get_item_info(item['name'])
        volume = info['volume'] if info else 0
        result.append({
            'name': item['name'],
            'quantity': item['quantity'],
            'volume': volume,
            'total_volume': volume * item['quantity']
        })
    return result
```
