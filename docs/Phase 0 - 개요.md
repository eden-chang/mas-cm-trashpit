# Phase 0 - 프로젝트 개요

## 목적

마스토돈 기반 TRPG 게임의 인벤토리를 **Supabase**(데이터베이스)와 **웹 인터페이스**(시각화)로 분리 관리하여, 운영진은 텍스트로 간편하게 관리하고 플레이어는 직관적인 그리드 UI로 아이템을 정리할 수 있도록 함

---

## 핵심 컨셉

- **3단계 인벤토리**: 가방(제한적) + 여유 공간(부피 0 아이템) + 주변(임시 보관)
- **역할 분리**: 운영진(DB 관리) / 봇(명령어 처리) / 플레이어(웹 정리)
- **단순한 부피 시스템**: 부피 단위 1부터, 근력에 따라 20/40/60 용량
- **자동 초기화**: 주변 아이템은 정기적으로 자동 삭제

---

## 구현할 명령어

| 명령어 | 설명 |
|--------|------|
| `[사용/아이템명]` | 아이템 사용 (효과 적용 후 소모) |
| `[양도/아이템명/이름]` | 다른 플레이어에게 아이템 전달 |
| `[양도/n포인트/이름]` | 다른 플레이어에게 포인트 전달 |
| `[버리기/아이템명]` | 아이템 삭제 |
| `[획득/아이템명]` | 아이템 획득 (주변에 추가) |

## 데이터 소스

### Supabase PostgreSQL

#### `characters` 테이블

| 컬럼 | 타입 | 용도 |
|------|------|------|
| name | text | 캐릭터 이름 (PK) |
| id | text | 마스토돈 계정 ID |
| side | text | 진영 (웨가/스카이) |
| con | integer | 체력 |
| str | integer | 근력 (가방 용량 계산) |
| luck | integer | 행운 |
| hp | integer | 현재 HP |
| points | integer | 소지금 |
| bag | jsonb | 가방 아이템 |
| misc | jsonb | 여유공간 아이템 |
| around | jsonb | 주변 아이템 |
| arrange | jsonb | 그리드 배치 정보 |

#### `items` 테이블

| 컬럼 | 타입 | 용도 |
|------|------|------|
| name | text | 아이템명 (PK) |
| price | text | 가격 또는 "비매품" |
| description | text | 아이템 설명 |
| use_script | text | 사용 시 출력 메시지 |
| change_stats | text | 영향 받는 스탯 |
| change_value | text | 스탯 변화량 |
| size | integer | 아이템 부피 |

## 인벤토리 구조

### A. 가방 (Bag)
- 캐릭터가 실제로 들고 다니는 아이템 공간
- 근력 1~5: 용량 20 / 근력 6~10: 용량 40 / 근력 11~15: 용량 60
- 부피 제한 있음
- 웹에서 테트리스 스타일로 정리

### B. 여유 공간 (Misc Space)
- 부피 0인 아이템 전용
- 용량 제한 없음
- 자동 편입

### C. 주변 (Nearby)
- 획득했지만 가방에 넣지 않은 아이템
- 기본 획득 위치
- 매일 0시 자동 삭제
- 가방에 넣거나, 사용하거나, 양도 가능

---

## 아이템 흐름

```
[아이템 획득] → [주변] → [가방에 넣기/사용/양도/버리기]
                  ↓
              (자동 삭제)

[부피 0 아이템 획득] → [여유 공간] (자동)
```
