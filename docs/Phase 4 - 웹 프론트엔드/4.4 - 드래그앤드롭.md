# 4.4 - 드래그앤드롭

## 개요

주변 → 가방, 가방 내 이동, 휴지통 버리기 등 DnD 요구사항입니다. **구현은 react-dnd (BagTab.tsx) 참조.**

---

## DnD 흐름

```
[주변 아이템] ─── dragstart ───► [드래그 중]
                                      │
                                 dragover
                                      │
              ┌───────────────────────┼───────────────────────┐
              │                       │                       │
         [가방 그리드]           [휴지통]              [드래그 취소]
              │                       │                       │
            drop                    drop                  dragend
              │                       │                       │
         [가방에 추가]           [아이템 삭제]          [원위치]
```

---

## 기능 요구사항

| 동작 | 요구사항 |
|------|----------|
| **주변 → 가방** | 공간 확인 후 `moveToBag` API 호출 |
| **가방 → 휴지통** | 확인 후 `discard` API 호출 |
| **주변 → 휴지통** | 확인 후 `discard` API 호출 |
| **드롭 가능 힌트** | 공간 충분 시 그리드/휴지통 하이라이트 |
