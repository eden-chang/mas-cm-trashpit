## trashpit 프로젝트 현황

| 구분 | 내용 |
|------|------|
| **웹 프론트** | `web/` - 바닐라 HTML/CSS/JS |
| **백엔드** | Flask API (`api/`) |
| **공유 모듈** | `shared/` - models, capacity, item_master 등 |

### API 엔드포인트 (Phase 3)

| Method | Endpoint | 용도 |
|--------|----------|------|
| GET | `/api/characters` | 캐릭터 목록 |
| GET | `/api/character/<name>` | 캐릭터 전체 정보 |
| GET | `/api/bag/<name>` | 가방 조회 |
| POST | `/api/bag/<name>` | 가방 업데이트 |
| GET | `/api/nearby/<name>` | 주변 아이템 조회 |
| POST | `/api/nearby/<name>/move` | 주변 → 가방 이동 |

## 데이터 모델 매핑

| Figma (BagTab) | API / shared | 비고 |
|----------------|--------------|------|
| `Item` (id, name, volume, gridPosition, shapeIndex) | `bag_items`: [{name, quantity}] | **그리드 위치 API에 없음** |
| `NearbyItem` | `nearby_items`: [{name, quantity, volume}] | quantity → 그룹화 count |
| `FreeItem` (부피 0) | `misc_items`: [{name, quantity}] | volume: 0 |
| `gridSize` | `bag_capacity` | 근력 기반 |
| `timeRemaining` | **없음** | Phase 5 예정 |

### 그리드 위치 처리 전략

| 전략 | 설명 | 권장 |
|------|------|------|
| **A. 클라이언트 자동배치** | API는 quantity만, 프론트에서 자동 배치 | ✓ 1차 |
| **B. API 확장** | `position`, `shape_index` 추가 | 추후 검토 |
| **C. 로컬 스토리지** | 배치는 로컬에만 저장 | 단기 대안 |
