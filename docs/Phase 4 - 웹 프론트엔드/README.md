# Phase 4 - 웹 프론트엔드

## 개요

React 기반 웹 인벤토리 관리 UI입니다. Figma에서 생성된 디자인 코드를 기반으로 Flask API와 연동합니다.

**기술 스택:**
- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- react-dnd (드래그앤드롭)
- 다크 테마 + Glassmorphism + Cyan/Purple 악센트

## 핵심 파일

### 소스 코드 (web/)

```
web/
├── src/
│   ├── app/
│   │   ├── App.tsx              # 메인 레이아웃
│   │   └── components/
│   │       ├── BagTab.tsx       # 가방 탭 (현재 1143줄, 분리 예정)
│   │       ├── FreeSpaceTab.tsx # 여유공간 탭
│   │       └── NearbyTab.tsx    # 주변 탭
│   ├── lib/
│   │   ├── api.ts               # API 클라이언트 (신규)
│   │   ├── transform.ts         # 데이터 변환 (신규)
│   │   └── types.ts             # TypeScript 타입 (신규)
│   └── components/ui/           # shadcn/ui 컴포넌트
├── package.json
├── vite.config.ts
└── .env
```
