# 4.3 - 여유공간 및 주변 UI

## 개요

여유공간(Misc)과 주변(Nearby) 탭의 UI 요구사항입니다. **구현은 `BagTab.tsx`, `FreeSpaceTab.tsx`, `NearbyTab.tsx` (Figma/React) 참조.**

---

## 여유공간 탭

| 항목 | 요구사항 |
|------|----------|
| **대상** | 부피 0 아이템 |
| **표시** | 리스트 (이름, 수량) |
| **제한** | 없음 |

---

## 주변 탭

| 항목 | 요구사항 |
|------|----------|
| **대상** | 획득했으나 가방에 넣지 않은 아이템 |
| **표시** | 리스트 (이름, 수량, 부피) |
| **경고** | 자동 삭제 안내 |
| **액션** | 가방에 넣기 버튼, 드래그로 가방 이동 |

---

## 데이터 흐름

- **로드**: `getCharacter` → `misc_items`, `nearby_items` 변환 후 표시
- **가방에 넣기**: `moveToBag` API 호출 → 재조회
