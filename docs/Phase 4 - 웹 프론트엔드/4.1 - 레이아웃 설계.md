# 4.1 - 레이아웃 설계

## 개요

웹 인터페이스의 전체 레이아웃 요구사항입니다. **실제 구현은 React 기반 Figma 디자인을 따릅니다.** → [4.5 - Figma 연동 개요 및 현황](./4.5%20-%20Figma%20연동%20개요%20및%20현황.md)

---

## 화면 구성 요구사항

| 영역 | 요구사항 |
|------|----------|
| **헤더** | 타이틀, 선택된 캐릭터 정보(이름, 근력), 메뉴 버튼 |
| **사이드바** | 캐릭터 목록, 선택 시 메인 영역 갱신 |
| **탭** | 가방 / 여유공간 / 주변 |
| **메인 콘텐츠** | 탭별 영역 (가방 그리드, 여유공간 리스트, 주변 아이템 리스트) |
| **액션 버튼** | Sync to Cloud, Refresh Data 등 |
