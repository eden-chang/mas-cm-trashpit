## HTML 구조

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>인벤토리 관리</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <!-- 헤더 -->
        <header class="header">
            <h1>인벤토리 관리</h1>
            <div class="user-info">
                <span id="character-name">발트</span>
                <span id="character-strength">(근력: 5)</span>
            </div>
        </header>

        <div class="main-layout">
            <!-- 사이드바: 캐릭터 목록 -->
            <aside class="sidebar">
                <h2>캐릭터</h2>
                <ul id="character-list">
                    <!-- 동적 생성 -->
                </ul>
                <button id="refresh-btn">새로고침</button>
            </aside>

            <!-- 메인 콘텐츠 -->
            <main class="content">
                <!-- 탭 -->
                <nav class="tabs">
                    <button class="tab active" data-tab="bag">가방</button>
                    <button class="tab" data-tab="misc">여유공간</button>
                    <button class="tab" data-tab="nearby">주변</button>
                </nav>

                <!-- 탭 콘텐츠 -->
                <div id="tab-content">
                    <!-- 동적 생성 -->
                </div>

                <!-- 액션 버튼 -->
                <div class="actions">
                    <button id="auto-arrange-btn">자동 정리</button>
                    <button id="save-btn" class="primary">저장</button>
                    <button id="cancel-btn">취소</button>
                </div>
            </main>
        </div>
    </div>

    <script src="app.js"></script>
</body>
</html>
```

## CSS 레이아웃

```css

    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

    background-color: #f5f5f5;
}

.container {
    max-width: 1200px;

    padding: 20px;
}
```
