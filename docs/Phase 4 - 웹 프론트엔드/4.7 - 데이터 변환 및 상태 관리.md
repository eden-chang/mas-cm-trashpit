### 자동배치 알고리즘

- 그리드: 10열, 행 수 = ceil(capacity / 10)
- 아이템 부피 순(큰 것 우선) 또는 문서 순으로 왼쪽 상단부터 채움
- SHAPES 패턴 중 shapeIndex: 0 사용

### API → Figma 변환 예시

```typescript
// bag_items → Item[]
function apiBagToGridItems(
  bagItems: { name: string; quantity: number; volume: number }[],
  capacity: number
): Item[] {
  const gridCols = 10;
  const gridRows = Math.ceil(capacity / gridCols);
  const occupied: boolean[][] = /* 초기화 */;
  const result: Item[] = [];
  let id = 0;

  for (const apiItem of bagItems) {
    for (let q = 0; q < apiItem.quantity; q++) {
      const pos = findFirstFit(apiItem.volume, occupied, gridRows, gridCols);
      if (pos) {
        result.push({
          id: `item-${++id}`,
          name: apiItem.name,
          count: 1,
          volume: apiItem.volume,
          gridPosition: pos,
          shapeIndex: 0,
        });
        markOccupied(pos, apiItem.volume, occupied);
      }
    }
  }
  return result;
}

// Item[] → API 저장용
function gridItemsToApiItems(items: Item[]): { name: string; quantity: number }[] {
  const map = new Map<string, number>();
  for (const item of items) {
    map.set(item.name, (map.get(item.name) ?? 0) + 1);
  }
  return Array.from(map.entries()).map(([name, quantity]) => ({ name, quantity }));
}
```

## 2. 상태 관리 및 데이터 흐름 (Phase 4.5.4)

### 작업 목록

| # | 작업 | 내용 |
|---|------|------|
| 1 | 캐릭터 선택 | `selectedCharacter` 변경 시 `getCharacter(name)` 호출 |
| 2 | 로컬 state | `bag_items`, `misc_items`, `nearby_items`를 React state로 보관 |
| 3 | DnD | 이벤트 시 로컬 state만 갱신 |
| 4 | hasUnsavedChanges | 로컬 state ≠ 마지막 fetch 결과 |
| 5 | 주변→가방 | `moveToBag` API 호출 후 `getCharacter` 재조회 |

### 데이터 흐름

```
[캐릭터 선택] → getCharacter(name)
     ↓
[API 응답] → transform → setItems, setFreeItems, setNearbyItems
     ↓
[DnD] → setItems 등 (로컬만)
     ↓
[SYNC TO CLOUD] → gridItemsToApiItems(items) → updateBag → getCharacter (재조회)
[Refresh Data] → getCharacter (재조회)
[주변→가방 DnD] → moveToBag → getCharacter (재조회)
```

### 저장(Sync) 시 변환

- Figma `Item[]` → API `items: [{name, quantity}]`
- 같은 name은 quantity로 합산
