## 5. Supabase API 오류

### 상황
네트워크 오류 또는 서버 문제

### 처리

```python
from postgrest.exceptions import APIError
import time
import logging

logger = logging.getLogger(__name__)

def safe_supabase_operation(func, *args, retries=3, **kwargs):
    """재시도 로직이 포함된 Supabase 작업"""
    for attempt in range(retries):
        try:
            return func(*args, **kwargs)
        except APIError as e:
            wait_time = 2 ** attempt
            logger.warning("Supabase API 오류, %d초 대기...", wait_time)
            time.sleep(wait_time)
        except Exception as e:
            logger.exception("Supabase 작업 실패: %s", e)
            if attempt == retries - 1:
                raise

    raise Exception("최대 재시도 횟수 초과")
```

### 사용자 응답

```python
try:
    result = safe_supabase_operation(update_bag, character, items)
except Exception as e:
    reply(status_id, "시스템 오류가 발생했습니다. 잠시 후 다시 시도해주세요.")
    logger.error("Supabase 오류: %s", e)
```

## 6. 마스토돈 API 오류

### 상황
봇 토큰 만료 또는 서버 오류

### 처리

```python
def safe_reply(status_id, message):
    """안전한 답글 전송"""
    try:
        mastodon.status_reply(
            to_status=mastodon.status(status_id),
            status=message,
            visibility='unlisted'
        )
    except MastodonUnauthorizedError:
        logger.error("Token expired!")
        # 관리자에게 알림
        notify_admin("Bot token expired")
    except MastodonAPIError as e:
        logger.error("Mastodon API error: %s", e)
        # 재시도 또는 큐에 저장
    except Exception as e:
        logger.error("Unexpected error: %s", e)
```

## 7. 잘못된 명령어 형식

### 상황
형식에 맞지 않는 명령어 입력

### 처리

```python
def parse_command(content):
    """명령어 파싱"""
    # HTML 태그 제거
    content = re.sub(r'<[^>]+>', '', content)

    for cmd_type, pattern in PATTERNS.items():
        match = pattern.search(content)
        if match:
            return (cmd_type, list(match.groups()))

    # 매칭되는 패턴 없음 - 무시
    return None
```

### 결과
- 잘못된 형식은 무시 (에러 메시지 없음)
- 봇이 관련 없는 멘션에 반응하지 않음

## 에러 로깅

```python
import logging
from datetime import datetime

logging.basicConfig(
    filename='bot.log',
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def log_error(error, context=None):
    """에러 로깅"""
    logging.error("Error: %s", error)
    if context:
        logging.error("Context: %s", context)

def log_command(user, command, result):
    """명령어 로깅"""
    logging.info("User: %s, Command: %s, Result: %s", user, command, result)
```
