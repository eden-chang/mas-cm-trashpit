# 시나리오 모음

## 시나리오 1: 아이템 획득 (정상)

```
1. 상황
   - 발트가 사과나무를 조사
   - GM이 사과 3개를 보상으로 지급

2. 플레이어 명령어
   @봇 [획득/사과]
   @봇 [획득/사과]
   @봇 [획득/사과]
   (또는 GM이 직접 시트에 추가)

3. 봇 처리
   - 상점 시트에서 "사과" 정보 확인 (부피: 1)
   - 발트의 "주변"에 사과 추가

4. 봇 응답
   @발트 사과를 획득했습니다! (부피: 1)
   가방 남은 공간: 5칸
   웹에서 가방에 넣으세요.

5. 플레이어 작업 (웹)
   - 웹사이트 접속
   - "주변" 탭에 사과 표시됨
   - 사과를 드래그해서 가방 그리드에 배치
   - [저장] 버튼 클릭

6. 결과
   - 가방: 15/20 → 18/20
   - 주변: 사과 사라짐
```

## 시나리오 2: 아이템 획득 (가방 꽉 참)

```
1. 상황

   - 의료키트(부피 5) 획득 시도

3. 봇 응답
   @발트 의료키트를 획득했습니다! (부피: 5)

   주변에 임시 보관됩니다. (자동 삭제 주의)

4. 플레이어 선택지
   A. 웹에서 기존 아이템 버리고 넣기
   B. 즉시 사용: @봇 [사용/의료키트]
   C. 다른 플레이어에게 양도: @봇 [양도/의료키트/엘리사]
```

## 시나리오 3: 아이템 사용

```
1. 상황
   - 발트의 가방에 사과 3개
   - 발트가 배고픔

2. 플레이어 명령어
   @봇 [사용/사과]

3. 봇 처리
   a. 주변 확인 → 없음
   b. 가방 확인 → 사과 3개 발견
   c. 상점에서 효과 확인: 체력 +3
   d. 체력 적용: 45 → 48
   e. 사과 차감: 3 → 2

4. 봇 응답
   @발트 사과를 먹었다! 상큼한 맛이 난다.
   효과: 체력 +3 (현재 체력: 48)
   남은 사과: 2개

5. 웹 화면
   - 가방에서 사과 1개 감소 반영
```

## 시나리오 4: 아이템 양도

```
1. 상황
   - 발트의 가방에 로프 1개 (부피 3)
   - 엘리사에게 로프를 주고 싶음

2. 플레이어 명령어
   @봇 [양도/로프/엘리사]

3. 봇 처리
   a. 로프 위치 확인 → 가방에 있음
   b. 발트 가방에서 로프 삭제
   c. 엘리사 주변에 로프 추가

4. 봇 응답
   @발트 로프를 엘리사에게 양도했습니다!

5. 엘리사에게 알림
   @엘리사 발트님이 로프를 양도했습니다!
   주변에서 확인하세요.

6. 웹 화면
   발트: 가방에서 로프 사라짐, 용량 -3
   엘리사: 주변 탭에 로프 추가
```

## 시나리오 5: 주변 아이템 자동 삭제

```
1. 상황
   - 발트의 주변에 배터리 2개
   - 발트가 가방 정리를 안 함
   - 자정이 됨

2. 시스템 처리 (자동)
   - 크론잡 실행 (매일 0시)
   - 모든 캐릭터의 "주변" 확인
   - 발트의 주변: 배터리 2개 삭제

3. 마스토돈 알림
   @발트
   ⚠️ 주변 아이템이 자동으로 삭제되었습니다:
   - 배터리 x2

   다음부터는 빨리 가방에 넣으세요!

4. 웹 화면
   - 주변 탭에서 배터리 사라짐
```

## 시나리오 6: 부피 0 아이템 자동 처리

```
1. 상황
   - 발트가 클립 3개를 발견
   - 상점 시트에서 클립 부피: 0

2. 플레이어 명령어
   @봇 [획득/클립]

3. 봇 처리 (특수 로직)
   a. 상점 시트 확인 → 클립 부피: 0
   b. 주변이 아닌 여유공간에 직접 추가

4. 봇 응답
   @발트 클립을 획득했습니다! (부피 0)
   자동으로 여유공간에 보관되었습니다.

5. 웹 화면
   - 주변 탭: 아무것도 안 나타남
   - 여유공간 탭: 클립 추가
```

## 시나리오 7: 포인트 양도

```

   - 엘리사에게 100 포인트 양도

2. 플레이어 명령어

3. 봇 처리
   a. 발트 포인트 확인: 350
   b. 100 >= 350? → OK
   c. 발트: 350 → 250
   d. 엘리사: +100

4. 봇 응답
   @발트 100포인트를 엘리사에게 양도했습니다!
   남은 포인트: 250

5. 엘리사에게 알림
   @엘리사 발트님이 100포인트를 양도했습니다!
```
