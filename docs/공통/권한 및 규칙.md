## 인벤토리 규칙

### 획득 규칙

1. **일반 아이템 (부피 1+)**: 주변에 추가
2. **부피 0 아이템**: 여유공간에 자동 추가
3. **가방 공간 부족**: 주변에 보관 (경고 표시)

### 사용 규칙

1. **사용 가능 아이템**: 사용문구가 있는 아이템만
2. **사용 우선순위**: 주변 → 가방 → 여유공간
3. **효과 적용**: 스탯 컬럼 자동 업데이트

### 양도 규칙

1. **자기 자신 양도**: 불가
2. **존재하지 않는 캐릭터**: 불가
3. **미소지 아이템**: 불가
4. **양도 위치**: 수신자의 주변 (부피 0은 여유공간)

### 버리기 규칙

1. **버리기 우선순위**: 주변 → 가방 → 여유공간
2. **1개씩 버리기**: 한 번에 1개만 삭제
3. **미소지 아이템**: 에러 메시지

## 저장 규칙

### 용량 검증

```
저장 시 검증:
1. 총 부피 계산 = Σ(아이템 부피 × 수량)
2. 총 부피 <= 가방 용량
3. 초과 시 저장 거부
```

### 충돌 처리

```
동시 편집 시:
1. 타임스탬프 비교
2. 불일치 시 충돌 경고
3. 새로고침 요청
```

## 자동 삭제 규칙

### 주변 아이템

- **삭제 시점**: 매일 0시
- **삭제 대상**: 모든 캐릭터의 '주변' 컬럼
- **알림**: 삭제 전/후 마스토돈 알림

### 예외 사항

- **가방 아이템**: 삭제 안 함
- **여유공간 아이템**: 삭제 안 함

## 보안 규칙

### 입력 검증

```python
# 아이템명 검증
def validate_item_name(name: str) -> bool:
    # 빈 문자열 불가
    if not name or not name.strip():
        return False
    # 특수문자 제한
    if any(char in name for char in ['/', '\\', '[', ']', ':']):
        return False
    return True

# 수량 검증
def validate_quantity(qty: int) -> bool:
    return isinstance(qty, int) and qty > 0 and qty <= 999
```

### 권한 검증

```python
def can_modify_character(user_id: str, char_name: str) -> bool:
    """캐릭터 수정 권한 확인"""
    char = get_character_by_name(char_name)

    # 본인 캐릭터
    if char['아이디'] == user_id:
        return True

    # GM 권한
    if is_admin(user_id):
        return True

    return False
```

## 에러 메시지

| 상황 | 메시지 |
|------|--------|
| 아이템 미소지 | `'{아이템명}'을(를) 소지하고 있지 않습니다.` |
| 사용 불가 | `'{아이템명}'은(는) 사용할 수 없는 아이템입니다.` |
| 존재하지 않음 | `'{아이템명}'은(는) 존재하지 않는 아이템입니다.` |
| 캐릭터 없음 | `'{이름}' 캐릭터를 찾을 수 없습니다.` |
| 자기 양도 | `자기 자신에게는 양도할 수 없습니다.` |
| 포인트 부족 | `포인트가 부족합니다. (보유: {n})` |
| 용량 초과 | `용량 초과 ({used}/{capacity})` |
