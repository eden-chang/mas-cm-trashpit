# Figma Make 프롬프트 가이드

이 문서는 **Trashpit 인벤토리 관리** 프로젝트의 웹 UI를 Figma Make로 빠르게 스케치할 때 사용할 프롬프트와 아이디어 정리 방법을 설명합니다.

---

## 1. Figma Make 프롬프트 기본 원칙

| 원칙 | 설명 |
|------|------|
| **역할 + 목적** | "웹 앱의 ~ 화면을 만들어줘"처럼 **무엇을** 만들지 먼저 명시 |
| **구조 나열** | 헤더, 사이드바, 탭, 그리드 등 **포함할 영역**을 짧게 나열 |
| **제약 조건** | **블랙 앤 화이트 스타일 유지**, 색상·폰트·언어(한글) 등 **반드시 지킬 것**만 간단히 |
| **한 번에 하나** | 전체 레이아웃 → 그 다음 컴포넌트처럼 **단계별**로 요청 |
| **예시 활용** | 원하는 스타일 이미지가 있으면 첨부해 "이 톤으로" 요청 |

**피할 것:** API 키·개인정보 입력, 지나치게 긴 한 덩어리 프롬프트, 모호한 표현("예쁘게", "간지나게"만 쓰지 말고 구체적으로)

---

## 2. 프로젝트 한 줄 요약 (컨텍스트용)

Figma Make 채팅에 **첫 메시지**로 넣을 때 참고:

> **"마스토돈 TRPG용 인벤토리 관리 웹 앱이야. 캐릭터별로 가방(테트리스 스타일 그리드), 여유공간, 주변 아이템을 탭으로 나누고, 왼쪽에 캐릭터 선택 사이드바가 있어. 블랙 앤 화이트 스타일을 유지해줘. 한글 UI, 모바일까지 고려한 반응형이면 좋겠어."**

---

## 3. 단계별 프롬프트 예시

### 3.1 전체 레이아웃 (1차)

```
인벤토리 관리 웹 앱의 메인 레이아웃을 만들어줘.

구조:
- 상단 헤더: 왼쪽에 "인벤토리 관리" 타이틀, 오른쪽에 "캐릭터명 (근력: 5)" 같은 사용자 정보
- 왼쪽 사이드바(고정): "캐릭터" 제목, 캐릭터 목록(이름 + 가방 용량 표시), 맨 아래 "새로고침" 버튼
- 오른쪽 메인: 상단에 탭 3개 (가방 | 여유공간 | 주변), 그 아래 넓은 콘텐츠 영역, 하단에 "자동 정리 / 저장 / 취소" 버튼

스타일: 블랙 앤 화이트 유지. 심플한 카드형, 흰 배경·회색·검정만 사용, 한글 UI. 데스크톱 기준으로 먼저.
```

**다음 단계:** "메인 콘텐츠 영역에 가방 탭 내용을 추가해줘"처럼 **한 영역씩** 채우기.

---

### 3.2 가방 탭 (그리드 + 목록)

```
방금 만든 레이아웃의 "가방" 탭 콘텐츠를 채워줘.

포함할 것:
1. 상단: "가방" 제목 + "15 / 20 사용" 같은 용량 표시
2. 테트리스 스타일 그리드: 정사각형 셀들이 격자로 배치 (예: 10열 x 4행), 빈 칸은 연한 회색, 아이템이 있는 칸은 검정 또는 진한 회색 배경
3. 그리드 아래: "보유 아이템" 리스트 (이름 x 개수, 부피)
4. 맨 아래: "휴지통 - 여기에 드래그하여 버리기" 드롭 존 (점선 테두리)

블랙 앤 화이트 스타일 유지. 한글 라벨 사용. 그리드 셀은 드래그 앤 드롭 대비해 hover 시 검정/진회색 테두리, 드롭 가능 구역은 연한 회색으로 구분해줘.
```

---

### 3.3 여유공간 탭

```
"여유공간" 탭 UI를 만들어줘.

- 제목 + "부피 0 아이템 전용 (제한 없음)" 설명
- 아이템을 칩/태그 형태로 나열 (이름 + x개수)
- 하단에 "부피가 0인 아이템은 자동으로 여기에 보관됩니다" 안내 문구

스타일: 블랙 앤 화이트 유지. 리스트보다는 가로로 흐르는 칩, 배경은 연한 회색(#f5f5f5), 한글.
```

---

### 3.4 주변 탭

```
"주변" 탭 UI를 만들어줘.

- 제목 + "자동 삭제 주의" 경고 문구
- 상단에 경고 박스: "주변 아이템은 정기적으로 자동 삭제됩니다. 가방에 넣거나 사용하세요!"
- 아이템 카드 리스트: 각 행에 아이템명, 부피, "가방에 넣기" 버튼 (공간 부족 시 비활성화)
- 하단 요약: "총 부피: N" / "가방 남은 공간: N"

스타일: 블랙 앤 화이트 유지. 경고는 진한 회색/검정 테두리·배경으로 구분, 버튼은 검정 또는 회색 primary. 한글.
```

---

### 3.5 디자인 토큰 (색·타이포)

스타일을 통일하고 싶을 때 채팅에 **추가 지시**로 넣을 수 있는 문구. **블랙 앤 화이트만 사용:**

```
블랙 앤 화이트 스타일을 유지해줘. 아래 디자인 토큰을 적용해줘.

배경: #FFFFFF, #F5F5F5, #FAFAFA
테두리: #EEEEEE, #DDDDDD, #CCCCCC
텍스트: #000000, #333333, #666666, #999999
강조(버튼/링크): #000000 또는 #333333
드롭가능/강조 영역: #E0E0E0, #BDBDBD
아이템 셀(가방): #212121 또는 #424242, 텍스트 #FFFFFF

색상은 흰색·회색·검정만 사용. 폰트: Noto Sans KR, 본문 14px, 제목은 1.25~1.5rem.
```

## 4. 반복 시 유용한 후속 프롬프트

| 목적 | 예시 문장 |
|------|-----------|
| 반응형 추가 | "이 레이아웃을 768px 이하에서 사이드바를 접히고, 탭과 버튼이 세로로 쌓이도록 반응형으로 바꿔줘." |
| 컴포넌트만 | "저장/취소 버튼만 primary(검정) / secondary(회색 테두리)로, 블랙 앤 화이트 유지해서 다시 그려줘." |
| 접근성 | "포커스 링과 대비 비율을 고려해서 버튼·탭 스타일을 조정해줘." |
| 데이터 연동 느낌 | "가방 그리드에 예시로 '사과 x3', '물병 x2'가 들어 있는 상태로 셀을 채워서 보여줘." |

## 5. 체크리스트 (Figma Make에 넣기 전)

- [ ] **역할/목적**이 한 문장으로 드러나는가? (인벤토리 관리 웹 앱, 한글)
- [ ] **블랙 앤 화이트 스타일 유지**를 명시했는가?
- [ ] **레이아웃 구조**(헤더, 사이드바, 탭, 그리드 등)를 나열했는가?
- [ ] **색/폰트**는 꼭 필요한 것만 짧게 넣었는가? (길면 "아래 토큰 적용"처럼 별도 메시지로)
- [ ] **한 번에 하나의 화면/영역**만 요청했는가?
- [ ] API 키·개인정보·비밀번호 등은 포함하지 않았는가?
