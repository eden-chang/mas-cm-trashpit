# Figma Make 프롬프트 가이드

이 문서는 **Trashpit 인벤토리 관리** 프로젝트의 웹 UI를 Figma Make로 빠르게 스케치할 때 사용할 프롬프트와 아이디어 정리 방법을 설명합니다.

> **Note:** 실제 구현된 디자인은 **다크 테마 + Glassmorphism + Cyan/Purple 악센트** 스타일입니다.
> 상세 스타일은 `공통/UI 디자인 가이드.md`를 참조하세요.

---

## 1. Figma Make 프롬프트 기본 원칙

| 원칙 | 설명 |
|------|------|
| **역할 + 목적** | "웹 앱의 ~ 화면을 만들어줘"처럼 **무엇을** 만들지 먼저 명시 |
| **구조 나열** | 헤더, 사이드바, 탭, 그리드 등 **포함할 영역**을 짧게 나열 |
| **제약 조건** | 다크 테마, Glassmorphism, Cyan/Purple 악센트, 한글 UI 등 |
| **한 번에 하나** | 전체 레이아웃 → 그 다음 컴포넌트처럼 **단계별**로 요청 |
| **예시 활용** | 원하는 스타일 이미지가 있으면 첨부해 "이 톤으로" 요청 |

**피할 것:** API 키·개인정보 입력, 지나치게 긴 한 덩어리 프롬프트, 모호한 표현("예쁘게", "간지나게"만 쓰지 말고 구체적으로)

---

## 2. 프로젝트 한 줄 요약 (컨텍스트용)

Figma Make 채팅에 **첫 메시지**로 넣을 때 참고:

> **"마스토돈 TRPG용 인벤토리 관리 웹 앱이야. 캐릭터별로 가방(테트리스 스타일 그리드), 여유공간, 주변 아이템을 탭으로 나누고, 오른쪽에 캐릭터 선택 사이드바가 있어. 다크 테마 + Glassmorphism 스타일, Cyan(#00F3FF)과 Purple(#BF5AF2) 악센트 색상을 사용해. 한글 UI, 모바일까지 고려한 반응형이면 좋겠어."**

---

## 3. 단계별 프롬프트 예시

### 3.1 전체 레이아웃 (1차)

```
인벤토리 관리 웹 앱의 메인 레이아웃을 만들어줘.

구조:
- 상단 헤더: 왼쪽에 "TRPG INVENTORY" 타이틀 (그라데이션 텍스트), 가운데에 "전사 | STR: 6" 같은 선택된 캐릭터 정보, 오른쪽에 햄버거 메뉴
- 왼쪽 메인 영역: 가방 그리드 + 하단에 Misc Space와 Nearby 영역
- 오른쪽 사이드바(고정): "CHARACTERS" 제목, 검색바, 캐릭터 목록(이름 + HP바 + 가방 용량 바), 맨 아래 "Sync to Cloud" / "Refresh Data" 버튼

스타일:
- 다크 테마: 배경 #0B0E14, 카드/패널 #1C2128
- Glassmorphism: backdrop-blur, rgba 배경, 미묘한 테두리
- 악센트: Cyan #00F3FF, Purple #BF5AF2
- 한글 UI. 데스크톱 기준으로 먼저.
```

**다음 단계:** "메인 콘텐츠 영역에 가방 그리드를 추가해줘"처럼 **한 영역씩** 채우기.

---

### 3.2 가방 탭 (그리드 + 목록)

```
방금 만든 레이아웃의 메인 영역에 가방 그리드를 채워줘.

포함할 것:
1. 상단: "Inventory Bag" 제목 + "15 / 60" 같은 용량 바 (progress bar, 상태별 색상 변화)
2. 테트리스 스타일 그리드: 정사각형 셀들이 격자로 배치 (10열 x 6행), 빈 칸은 rgba(255,255,255,0.03) + 미묘한 테두리, 아이템이 있는 칸은 Cyan 테두리 + 글로우
3. 그리드 옆/아래: 휴지통 드롭 존 (빨간색 점선 테두리, Trash 아이콘)

스타일:
- 다크 테마 유지
- 아이템 셀: rgba(0, 243, 255, 0.15) 배경, Cyan 테두리
- 드롭 가능 시: 녹색 glow 효과
- 한글 라벨 사용
```

---

### 3.3 여유공간 영역 (Misc Space)

```
"Misc Space" 영역을 만들어줘.

- 좌측 하단에 위치
- 제목: "MISC SPACE" + 배지로 아이템 개수 표시
- 부피 0 아이템을 칩/태그 형태로 나열 (이름 + x개수)
- 연한 Cyan 테두리, 어두운 배경

스타일: 다크 테마 + Glassmorphism 유지. 칩은 작은 rounded 버튼 스타일, 한글.
```

---

### 3.4 주변 아이템 영역 (Nearby)

```
"Nearby Items" 영역을 만들어줘.

- Misc Space 옆에 위치
- 제목: "NEARBY ITEMS" + 자동 삭제 타이머 표시 "DELETE IN 08:45:22"
- 아이템 카드 리스트: 각 카드에 아이템명, 부피 표시, 드래그 가능
- 경고 느낌: Purple 악센트, 타이머는 Warning 색상

스타일:
- 다크 테마 + Glassmorphism
- Purple (#BF5AF2) 테두리/악센트
- 타이머: #FFB020 (warning)
- 한글
```

---

### 3.5 디자인 토큰 (색·타이포)

스타일을 통일하고 싶을 때 채팅에 **추가 지시**로 넣을 수 있는 문구:

```
다크 테마 + Glassmorphism 스타일을 유지해줘. 아래 디자인 토큰을 적용해줘.

배경:
- Base: #0B0E14
- Raised: #1C2128
- Overlay: #2A2F3A

테두리: rgba(255, 255, 255, 0.1~0.3)

텍스트:
- Primary: #FFFFFF
- Secondary: rgba(255, 255, 255, 0.7)
- Muted: rgba(255, 255, 255, 0.5)

악센트:
- Cyan: #00F3FF (Primary 액션, 아이템)
- Purple: #BF5AF2 (Secondary, Nearby)

상태:
- Success: #00FF88
- Warning: #FFB020
- Danger: #FF4757

Glassmorphism:
- backdrop-filter: blur(12px)
- 반투명 배경: rgba(28, 33, 40, 0.8)
- 미묘한 glow 효과

폰트: Inter 또는 Noto Sans KR, 본문 14px, 제목은 1.25~1.5rem
```

## 4. 반복 시 유용한 후속 프롬프트

| 목적 | 예시 문장 |
|------|-----------|
| 반응형 추가 | "이 레이아웃을 768px 이하에서 사이드바를 하단 드로어로 변경하고, 햄버거 메뉴로 토글하도록 바꿔줘." |
| 컴포넌트만 | "Sync to Cloud 버튼을 Cyan 그라데이션 + glow 효과로 다시 그려줘." |
| Glow 효과 | "아이템 셀에 hover 시 box-shadow: 0 0 15px rgba(0, 243, 255, 0.3) 효과를 추가해줘." |
| 데이터 연동 느낌 | "가방 그리드에 예시로 '사과 x3', '물병 x2'가 들어 있는 상태로 셀을 채워서 보여줘." |

## 5. 체크리스트 (Figma Make에 넣기 전)

- [ ] **역할/목적**이 한 문장으로 드러나는가? (인벤토리 관리 웹 앱, 한글)
- [ ] **다크 테마 + Glassmorphism + Cyan/Purple 악센트**를 명시했는가?
- [ ] **레이아웃 구조**(헤더, 사이드바, 그리드, 영역 등)를 나열했는가?
- [ ] **색/폰트**는 꼭 필요한 것만 짧게 넣었는가? (길면 "아래 토큰 적용"처럼 별도 메시지로)
- [ ] **한 번에 하나의 화면/영역**만 요청했는가?
- [ ] API 키·개인정보·비밀번호 등은 포함하지 않았는가?
