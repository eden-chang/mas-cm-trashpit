# 봇 명령어 테스트 체크리스트

마스토돈 봇(@봇계정)에 멘션으로 테스트합니다.
두 개의 테스트 캐릭터 계정이 필요합니다.

## 사전 준비

| 항목 | 값 |
|------|---|
| 봇 계정 | @\_\_\_\_\_\_ |
| 테스트 계정 A (일반) | @\_\_\_\_\_\_ (캐릭터명: \_\_\_\_\_\_) |
| 테스트 계정 B (일반) | @\_\_\_\_\_\_ (캐릭터명: \_\_\_\_\_\_) |
| 관리자 계정 | @\_\_\_\_\_\_ (SYSTEM_ADMIN_ID에 등록된 계정) |

---

## 1. 시작 시 과거 알림 무시 확인

| # | 테스트 | 방법 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 0-1 | 봇 시작 전 명령어 무시 | 봇 종료 상태에서 `[상점]` 멘션 전송 후 봇 시작 | 로그에 "기존 알림 N개 건너뜀" 표시, 답장 없음 | [ ] |
| 0-2 | 봇 시작 후 명령어만 처리 | 봇 시작 후 `[상점]` 멘션 전송 | 정상 답장 옴 | [ ] |

---

## 2. 인벤토리 명령어

### [획득/아이템명]

| # | 테스트 | 입력 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 2-1 | 정상 획득 | `[획득/사과]` | 사과 획득 성공, 부피/남은공간 표시 | [ ] |
| 2-2 | 존재하지 않는 아이템 | `[획득/없는아이템123]` | 아이템 정보를 찾을 수 없음 에러 | [ ] |
| 2-3 | 빈 이름 | `[획득/]` | 에러 또는 무시 | [ ] |

### [버리기/아이템명]

| # | 테스트 | 입력 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 3-1 | 정상 버리기 | `[버리기/사과]` | 사과 1개 버림 성공 | [ ] |
| 3-2 | 소지하지 않은 아이템 | `[버리기/없는아이템]` | 인벤토리에 없음 에러 | [ ] |

### [사용/아이템명]

| # | 테스트 | 입력 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 4-1 | 정상 사용 | `[사용/반창고]` | 사용 효과 메시지 + 남은 수량 표시 | [ ] |
| 4-2 | 미소지 아이템 사용 | `[사용/없는아이템]` | 소지하지 않은 아이템 에러 | [ ] |
| 4-3 | 마지막 1개 사용 | 1개만 남은 상태에서 `[사용/아이템]` | "(마지막 아이템명)" 표시 | [ ] |

## 3. 양도 명령어

### [양도/아이템명/캐릭터명]

| # | 테스트 | 입력 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 5-1 | 아이템 양도 성공 | `[양도/사과/캐릭터B]` | 양도 성공, 상대방에게 알림 DM | [ ] |
| 5-2 | 미소지 아이템 양도 | `[양도/없는아이템/캐릭터B]` | 소지 부족 에러 | [ ] |
| 5-3 | 존재하지 않는 캐릭터 | `[양도/사과/없는캐릭터]` | 캐릭터를 찾을 수 없음 에러 | [ ] |
| 5-4 | 자기 자신에게 양도 | `[양도/사과/자기캐릭터]` | 자기 자신에게 양도 불가 에러 | [ ] |
| 5-5 | 여러 아이템 양도 | `[양도/사과,담배/캐릭터B]` | 각 아이템별 성공/실패 표시 | [ ] |

### [양도/n포인트/캐릭터명]

| # | 테스트 | 입력 | 예상 결과 | Pass |
|---|--------|------|-----------|------|
| 6-1 | 포인트 양도 성공 | `[양도/10포인트/캐릭터B]` | 10포인트 차감, 상대방 +10 | [ ] |
| 6-2 | 잔액 부족 | `[양도/999999포인트/캐릭터B]` | 포인트 부족 에러 | [ ] |
| 6-3 | 0 포인트 양도 | `[양도/0포인트/캐릭터B]` | 0 이하 불가 에러 | [ ] |

## 4. 관리자 명령어 (SYSTEM_ADMIN_ID 계정에서만)

## 테스트 순서 권장

1. **8번 (무시 테스트)** 먼저 - 다른 봇 간섭 방지 확인이 최우선
2. **0번** - 시작 시 과거 알림 무시 확인
3. **6번** - 상점/설명 (데이터 변경 없는 조회)
4. **5번** - 스탯 변경 (되돌리기 쉬움)
5. **7번** - 전투 (조회성)
6. **2번** - 획득/버리기/사용
7. **3번** - 양도
8. **4번** - 관리자 명령어 (마지막)
