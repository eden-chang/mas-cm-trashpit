A. 인벤토리의 구조

===================
# # # # # # # # # # # # # # # 
===================

우선 인벤토리를 3가지 항목으로 나눕니다.

1) 가방
2) 여유 공간
3) 주변

===================

1) 가방

가방은 부피가 제한된 공간입니다.

근력이 1~5인 경우 20만큼을 들 수 있고,
근력이 6~10인 경우 40만큼을,
근력이 11~15인 경우 60만큼을 들 수 있습니다.

아이템의 부피 단위는 1부터 시작합니다.

===================

2) 여유 공간

여유 공간에는 부피가 0인 아이템이 들어갑니다.
획득한 아이템 중 부피가 0인 경우에는 무조건 여유 공간으로 편입됩니다.

===================

3) 주변

획득한 아이템은 우선 가방으로 들어가지 않고, '주변'에 남아 있습니다.
운영진이 조사나 전투 중 획득한 아이템을 추가할 경우, '주변' 에 추가합니다.

주변에 있는 아이템은 바로 사용하거나, 바로 양도할 수 있습니다.
다만, 가방에 넣지 않는 이상 들고갈 수는 없습니다.

'주변' 항목은 매일 0시에 아무것도 없도록 초기화됩니다. (혹은 한시간마다, 또는 반나절마다 초기화할수도)

B. 인벤토리의 관리

===================
# # # # # # # # # # # # # # # 
===================

1) 구글 시트
2) 웹페이지

===================

1) 구글 시트 - 운영진과 자동봇이 접근

운영진이 관리하는 건 구글 시트에 텍스트로 정리된 내용뿐입니다.
캐릭터의 '주변'에 아이템을 추가하고, 상점에 어떤 아이템이 어떤 기능을 하는지, 그리고 얼마 만큼의 부피를 갖는지를 작성합니다.
그럼 운영진이 작성한 정보를 자동봇과 웹사이트가 활용하게 됩니다.

===================

2) 웹페이지 - 자동봇과 유저가 접근

마인크래프트나 스타듀밸리의 인벤토리처럼 네모난 그리드를 시각화해서 보여줍니다.
전달해주신 시트와 큰 차이점은 없죠.

다만, 시트와 다른 점은 이 항목에서 아이템을 드래그-드롭으로 추가하거나, 빼거나, 버릴 수 있다는 점입니다.

가장 먼저 아이템을 획득하면 아이템은 기본적으로 '주변' 으로 들어갑니다.
유저는 이 주변에 있는 아이템을 웹사이트에서 가방에 끌어다 놓을 수 있습니다.
'저장' 버튼을 누르면, 이 아이템의 편입이 구글 시트에 반영됩니다.

C. 아이템 획득, 사용, 양도

===================
# # # # # # # # # # # # # # # 
===================

1) 아이템 획득

자, 만약 발트라는 친구가 사과나무 주변에 갔다고 해봅시다.
발트는 조사를 통해 사과를 3개 획득했습니다.
운영진은 명령어를 사용해 캐릭터의 주변에 사과를 놔줍니다.
이때, 사과는 '상점' 탭에 사용시 체력이 +3 되고, 무게는 1이라고 지정당한 상태입니다.

@BOT [아이템 추가/발트의 주변/사과 3개]

발트가 웹사이트를 확인하면, 그리드 형태의 가방 주변 공간에 '사과'라고 써있는 글씨가 3개 생길 겁니다.
발트는 그걸 끌어다가 1개 칸에 놓을 수 있겠죠.
가방이 텅 비어있다면 사과 3개를 총 3개의 칸에 하나씩 넣었을 겁니다.

그리고 저장 버튼을 누릅니다.

그럼 이제 구글시트에서 원래 '주변' 열에 존재하던 '사과: 3' 항목이
'가방' 으로 이동했을 겁니다.

===================

2) 아이템 사용

2일차에 발트는 배가 고파져서 사과를 먹으려고 합니다.

[사용/사과] 명령어를 입력하면 자동봇은 자동으로 다음의 과정을 처리합니다.

1. 어? 발트가 사과를 사용하려고 하네? 일단 발트의 주변을 살펴볼까? 아 주변에는 사과가 없군.
2. 그럼 발트의 가방 안에 사과가 있나?
3. 오, 사과가 있다! 사용할 수 있겠어.
4. 상점 시트를 살펴보니 사과는 체력을 3 올려주는군!
5. 발트의 체력을 3 올려주고 시트에서 사과 아이템을 삭제해야지.
6. 그리고 웹페이지 연동 버튼을 클릭해서 이제 발트의 가방 안에 사과가 하나 없도록 바꿀거야!

이 과정을 통해 발트는 체력이 3 증가하고, 가방 안에 사과가 1개 사라진 효과를 겪게 됩니다.
