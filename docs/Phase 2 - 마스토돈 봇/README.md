### 플레이어 명령어

| 명령어 | 기능 | 예시 |
|--------|------|------|
| `[획득/아이템명]` | 아이템 획득 | `[획득/사과]` |
| `[버리기/아이템명]` | 아이템 삭제 | `[버리기/돌멩이]` |

## 기술 스택

- **Mastodon.py**: 마스토돈 API 클라이언트
- **gspread**: 구글 시트 연동
- **Python 3.11+**: 타입 힌트, Pydantic 모델

---

## 주요 시스템

### 1. 인벤토리 시스템

아이템은 3개 위치에 보관됩니다:
- **주변**: 부피 1+ 아이템 임시 보관 (획득 시 기본 배치)
- **가방**: 용량 제한 있음, 웹에서 직접 관리
- **여유공간**: 부피 0 아이템 무제한 보관

### 2. 부피 시스템

- **부피 0**: 여유공간에 자동 보관 (무게 없는 아이템)
- **부피 1+**: 주변에 배치 후 가방으로 이동 필요

### 3. 다이스 시스템

아이템 사용 시 효과 랜덤화:
- 지원 형식: `정수`, `ndm`, `ndm+k`, `ndm-k`, `-(ndm+k)`
- 예시: `10`, `1d10`, `1d6+3`, `1d6-2`, `-(1d6+3)`

### 4. 알림 시스템

- **답글**: 명령어 실행 결과 (unlisted 가시성)
- **DM**: 양도 수신 시 상대방에게 알림

```
│   ├── transfer.py    # 양도
│   └── grant.py       # 지급 (운영진)
├── services/          # 비즈니스 로직
│   ├── character_service.py
│   ├── inventory_service.py
│   └── item_service.py
└── main.py           # 폴링 루프
```
