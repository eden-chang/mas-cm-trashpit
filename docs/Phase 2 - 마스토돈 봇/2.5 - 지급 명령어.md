# 2.5 - 지급 명령어 (운영진 전용)

## 개요

운영진이 캐릭터에게 아이템을 지급하는 명령어입니다.

---

## [지급/캐릭터명/아이템명]

운영진이 특정 캐릭터에게 아이템을 지급합니다.

### 권한 확인

```python
def is_admin(mastodon_id: str) -> bool:
    """운영진 여부 확인"""
    admin_list = os.getenv('SYSTEM_ADMIN_ID', '').split(',')
    return mastodon_id in admin_list
```

### 처리 흐름

```
1. 운영진 권한 확인
2. 대상 캐릭터 존재 확인
3. 아이템 정보 확인
4. 부피에 따른 자동 배치
   - 부피 0 → 여유공간
   - 부피 1+ → 주변
5. 시트 업데이트
6. 응답 전송
```

### 구현

```python
def handle_give_admin(status_id: str, user: str, character: dict, args: list):
    """[지급/캐릭터명/아이템명] 처리 (운영진 전용)"""
    target_name = args[0].strip()
    item_name = args[1].strip()
    
    # 권한 확인
    if not is_admin(user):
        reply(status_id, f"@{user} 이 명령어는 운영진만 사용할 수 있습니다.")
        return
    
    # 대상 캐릭터 확인
    target = get_character_by_name(target_name)
    if not target:
        reply(status_id, f"@{user} '{target_name}' 캐릭터를 찾을 수 없습니다.")
        return
    
    # 아이템 정보 확인
    item_info = get_item_info(item_name)
    if not item_info:
        reply(status_id, f"@{user} '{item_name}'은(는) 존재하지 않는 아이템입니다.")
        return
    
    volume = item_info['volume']
    
    # 부피에 따라 자동 배치
    if volume == 0:
        # 여유공간에 추가
        add_to_misc(target_name, item_name, 1)
        reply(status_id,
            f"@{user} {target_name}에게 {item_name}을(를) 지급했습니다! (부피 0)\n"
            f"자동으로 여유공간에 보관되었습니다.")
    else:
        # 주변에 추가
        add_to_nearby(target_name, item_name, 1)
        available = get_available_space(target_name)
        
        reply(status_id,
            f"@{user} {target_name}에게 {item_name}을(를) 지급했습니다! (부피: {volume})\n"
            f"주변에 배치되었습니다. (가방 남은 공간: {available}칸)")
```

## 응답 예시

### 성공 (부피 0)

```
@longwhile 홍길동에게 사과를(를) 지급했습니다! (부피 0)
자동으로 여유공간에 보관되었습니다.
```

### 성공 (부피 1+)

```
@longwhile 홍길동에게 회복 물약을(를) 지급했습니다! (부피: 1)
주변에 배치되었습니다. (가방 남은 공간: 5칸)
```

### 에러: 권한 없음

```
@user123 이 명령어는 운영진만 사용할 수 있습니다.
```

### 에러: 대상 캐릭터 없음

```
@longwhile '존재하지않는이름' 캐릭터를 찾을 수 없습니다.
```

### 에러: 아이템 없음

```
@longwhile '존재하지않는아이템'은(는) 존재하지 않는 아이템입니다.
```

---

## 주의사항

1. **권한 확인 필수**: 모든 지급 명령은 운영진 권한을 먼저 확인해야 합니다.
2. **자동 배치**: 획득 명령어와 동일한 로직으로 부피에 따라 자동 배치됩니다.
3. **알림**: 대상 캐릭터에게는 별도 알림이 가지 않습니다. (운영진이 직접 공지)
4. **수량 고정**: 현재는 1개씩만 지급 가능합니다. 여러 개 지급 시 명령어를 반복해야 합니다.
