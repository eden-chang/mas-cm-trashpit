# 1.3 - 용량 계산 규칙

## 개요

캐릭터의 근력 스탯에 따라 가방 용량이 결정됩니다.

---

## 근력별 용량

| 근력 | 가방 용량 |
|------|----------|
| 1~5 | 20 |
| 6~10 | 40 |
| 11~15 | 60 |
| 16~20 | 80 |

```python
def calculate_capacity(strength: int) -> int:
    """근력 기반 가방 용량 계산"""
    if 1 <= strength <= 5:
        return 20
    elif 6 <= strength <= 10:
        return 40
    elif 11 <= strength <= 15:
        return 60
    elif 16 <= strength <= 20:
        return 80
    else:
        return 20  # 기본값
```

## 사용량 계산 함수

```python
def parse_inventory(inventory_str: str) -> list[dict]:
    """인벤토리 문자열 파싱

    '사과: 3, 물병: 2' -> [{'name': '사과', 'quantity': 3}, ...]

    참고: 콜론 뒤 공백, 콤마 뒤 공백이 있을 수 있음 (strip으로 처리)
    """
    if not inventory_str or inventory_str.strip() == '':
        return []

    items = []
    for item in inventory_str.split(','):
        item = item.strip()
        if ':' in item:
            name, qty = item.split(':')
            items.append({
                'name': name.strip(),
                'quantity': int(qty.strip())
            })
    return items

def calculate_used_volume(inventory_str: str) -> int:
    """가방 사용량 계산"""
    items = parse_inventory(inventory_str)
    total = 0

    for item in items:
        item_info = get_item_info(item['name'])
        if item_info:
            total += item_info['volume'] * item['quantity']

    return total

def get_available_space(character_name: str) -> int:
    """남은 가방 공간 계산"""
    char = get_character(character_name)
    capacity = calculate_capacity(char['근력'])
    used = calculate_used_volume(char['가방'])
    return capacity - used

def can_add_item(character_name: str, item_name: str, quantity: int = 1) -> bool:
    """아이템 추가 가능 여부"""
    item_info = get_item_info(item_name)
    if not item_info:
        return False

    # 부피 0은 여유공간으로 가므로 항상 가능
    if item_info['volume'] == 0:
        return True

    needed = item_info['volume'] * quantity
    available = get_available_space(character_name)
    return needed <= available
```

## 여유공간 규칙

- 부피 0인 아이템은 **자동으로 여유공간**에 저장
- 용량 제한 없음
- 가방 용량에 영향 없음

```python
def add_item_to_character(character_name: str, item_name: str, quantity: int):
    """아이템 추가 (자동 분류)"""
    item_info = get_item_info(item_name)

    if item_info['volume'] == 0:
        # 여유공간에 추가
        add_to_misc(character_name, item_name, quantity)
    else:
        # 주변에 추가 (가방은 웹에서 정리)
        add_to_nearby(character_name, item_name, quantity)
```
