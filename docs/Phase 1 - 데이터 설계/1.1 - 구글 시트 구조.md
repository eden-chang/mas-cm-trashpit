# 1.1 - 구글 시트 구조

## 개요

모든 데이터는 구글 시트에서 관리됩니다.

- **Sheet ID**: `1JrUVHRj7fKpvX-cP98J13Asx6h-FEydAPCm0q7l1exk`
- **행 구조**: 1행 헤더, 2행 정보행, 3행부터 실제 데이터

---

## '관리' 워크시트

캐릭터 정보와 인벤토리를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 | 사용 여부 |
|------|------|------|----------|
| 이름 | string | 캐릭터 이름 | O |
| 아이디 | string | 마스토돈 계정 ID (예: TP_Mst) | O |
| 진영 | string | 소속 진영 (웨가/스카이) | O |
| 체력 | number | 캐릭터 체력 | O |
| 근력 | number | 가방 용량 계산 | O |
| 행운 | number | 캐릭터 행운 | O |
| 가방 | string | 가방 아이템 목록 | O |
| 여유공간 | string | 부피 0 아이템 목록 | O |
| 주변 | string | 임시 보관 아이템 | O |

### 진영 정보

| 진영 | 설명 |
|------|------|
| 웨가 | 근력 사용 팀 |
| 스카이 | 근력 미사용 팀 |

### 데이터 형식 예시

```
| 이름 | 아이디 | 진영 | 체력 | 근력 | 행운 | 가방 | 여유공간 | 주변 |
|------|--------|------|------|------|------|------|----------|------|
| 총괄 | TP_Mst | 웨가 | 103 | 5 | 80 | 담배: 1, 바나나: 2, 반지: 1 | | |
| 스토리 | TP_Story | 스카이 | 100 | 10 | 50 | 반지: 1, 사과: 3 | | |
| 발트 | TP_Balt | 스카이 | 14 | 13 | 1 | | | |
```

### 아이템 저장 형식

가방, 여유공간, 주변 컬럼은 텍스트로 아이템을 저장합니다.

```
아이템명: 수량, 아이템명: 수량, ...
```

**주의**: 콜론(`:`) 뒤에 공백이 있고, 각 아이템은 콤마와 공백(`, `)으로 구분됩니다.

예시:
- `담배: 1, 바나나: 2, 반지: 1`
- `반지: 1, 사과: 3`

## '상점' 워크시트

아이템 마스터 정보를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 |
|------|------|------|
| 아이템명 | string | 아이템 고유 이름 (**제한**: `/`, `,`, `:` 사용 불가) |
| 가격 | number/string | 구매 가격 (정수) 또는 `비매품` |
| 설명 | string | 아이템 설명 (`[설명/아이템명]` 명령어 시 출력) |
| 사용문구 | string | 사용 시 출력 메시지 (사용 불가 아이템은 공란) |
| 스탯 | string | 영향 받는 스탯 (체력, 근력, 행운) 또는 `사용 불가` |
| 수치 | string | 스탯 변화량 (정수 또는 다이스 표기법) |
| 부피 | number | 차지하는 공간 (0 = 여유공간) |

### 수치 필드 형식

수치 필드는 다음 형식을 지원합니다:

| 형식 | 예시 | 설명 |
|------|------|------|
| 정수 | `10`, `-2` | 고정 수치 |
| 다이스 | `1d10` | n면체 주사위 m개 |
| 다이스+보정 | `1d6+3` | 주사위 + 고정값 |
| 다이스-보정 | `1d6-2` | 주사위 - 고정값 |
| 음수 다이스 | `-(1d6+3)` | 마이너스 효과 |

### 데이터 예시

```
| 아이템명 | 가격 | 설명 | 사용문구 | 스탯 | 수치 | 부피 |
|----------|------|------|----------|------|------|------|
| 반지 | 70 | 노란색 보석이 박힌 은색 반지다. | 반지가 번쩍이며 정신이 말끔해진다. | 근력 | 10 | 0 |
| 사과 | 20 | 아삭아삭! | 달콤한 사과의 맛! | 체력 | 1d10 | 1 |
| 바나나 | 20 | 부드럽고 달콤하고... | 어라? 나... 바나나 알러지가 있었을지도? | 체력 | -2 | 2 |
| 아몬드 | 비매품 | 사실은 청산가리입니다. | 청산가리를 먹자 호흡이 가빠진다. | 체력 | -(1d6+3) | 0 |
| 파란 꽃병 | 50 | 꽃을 꽂아둘 수 있습니다. 관상용 아이템입니다. | | 사용 불가 | | 2 |
```

## 접근 방식

```python
import gspread
from oauth2client.service_account import ServiceAccountCredentials

# 인증
scope = ['https://spreadsheets.google.com/feeds',
         'https://www.googleapis.com/auth/drive']
creds = ServiceAccountCredentials.from_json_keyfile_name('credentials.json', scope)
client = gspread.authorize(creds)

# 시트 열기
sheet = client.open_by_key(SHEET_ID)

# 워크시트 접근
management_ws = sheet.worksheet('관리')
shop_ws = sheet.worksheet('상점')

# 데이터 읽기 (3행부터)
characters = management_ws.get_all_records()[1:]  # 2행 정보행 스킵
items = shop_ws.get_all_records()[1:]
```
