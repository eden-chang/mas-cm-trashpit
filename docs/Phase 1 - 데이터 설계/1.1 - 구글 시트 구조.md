# 1.1 - 구글 시트 구조

## 개요

모든 데이터는 구글 시트에서 관리됩니다.

- **Sheet ID**: `1JrUVHRj7fKpvX-cP98J13Asx6h-FEydAPCm0q7l1exk`
- **행 구조**: 1행 헤더, 2행 정보행, 3행부터 실제 데이터

---

## '관리' 워크시트

캐릭터 정보와 인벤토리를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 | 사용 여부 |
|------|------|------|----------|
| 이름 | string | 캐릭터 이름 | O |
| 아이디 | string | 마스토돈 계정 ID | O |
| 진영 | string | 소속 진영 | X |
| 체력 | number | 캐릭터 체력 | O |
| 근력 | number | 가방 용량 계산 | O |
| 행운 | number | 캐릭터 행운 | O |
| 가방 | string | 가방 아이템 목록 | O |
| 여유공간 | string | 부피 0 아이템 목록 | O |
| 주변 | string | 임시 보관 아이템 | O |

### 데이터 형식 예시

```
| 이름 | 아이디 | 체력 | 근력 | 행운 | 가방 | 여유공간 | 주변 |
|------|--------|------|------|------|------|----------|------|
| 발트 | balt   | 50   | 5    | 3    | 사과:3,물병:2 | 클립:2,동전:5 | 의료키트:1 |
```

### 아이템 저장 형식

가방, 여유공간, 주변 컬럼은 텍스트로 아이템을 저장합니다.

```
아이템명:수량,아이템명:수량,...
```

예시:
- `사과:3,물병:2,손전등:1`
- `클립:2,동전:5,성냥:1`

## '상점' 워크시트

아이템 마스터 정보를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 |
|------|------|------|
| 아이템명 | string | 아이템 고유 이름 |
| 가격 | number | 구매 가격 |
| 설명 | string | 아이템 설명 |
| 사용문구 | string | 사용 시 출력 메시지 |
| 스탯 | string | 영향 받는 스탯 (체력, 행운 등) |
| 수치 | number | 스탯 변화량 (+/-) |
| 부피 | number | 차지하는 공간 (0 = 여유공간) |

### 데이터 예시

```
| 아이템명 | 가격 | 설명 | 사용문구 | 스탯 | 수치 | 부피 |
|----------|------|------|----------|------|------|------|
| 사과 | 10 | 신선한 사과 | 사과를 먹었다! | 체력 | 3 | 1 |
| 의료키트 | 50 | 응급처치 도구 | 치료를 받았다! | 체력 | 10 | 5 |
| 클립 | 1 | 작은 클립 | - | - | 0 | 0 |
```

## 접근 방식

```python
import gspread
from oauth2client.service_account import ServiceAccountCredentials

# 인증
scope = ['https://spreadsheets.google.com/feeds',
         'https://www.googleapis.com/auth/drive']
creds = ServiceAccountCredentials.from_json_keyfile_name('credentials.json', scope)
client = gspread.authorize(creds)

# 시트 열기
sheet = client.open_by_key(SHEET_ID)

# 워크시트 접근
management_ws = sheet.worksheet('관리')
shop_ws = sheet.worksheet('상점')

# 데이터 읽기 (3행부터)
characters = management_ws.get_all_records()[1:]  # 2행 정보행 스킵
items = shop_ws.get_all_records()[1:]
```
