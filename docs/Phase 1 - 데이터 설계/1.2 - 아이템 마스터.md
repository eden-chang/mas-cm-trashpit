# 1.2 - 아이템 마스터

## 개요

'상점' 워크시트에서 모든 아이템의 마스터 정보를 관리합니다.

---

## 아이템 속성

### 필수 속성

| 속성 | 설명 |
|------|------|
| 아이템명 | 고유 식별자 (중복 불가, `/`, `,`, `:` 사용 불가) |
| 부피 | 가방 공간 차지량 (0 = 여유공간으로 자동 이동) |

### 선택 속성

| 속성 | 설명 |
|------|------|
| 가격 | 구매/판매 시 사용 (정수 또는 `비매품`) |
| 설명 | 아이템 설명 텍스트 |
| 사용문구 | `[사용]` 명령어 시 출력 메시지 (공란 = 사용 불가) |
| 스탯 | 영향 받는 스탯 (체력, 근력, 행운) 또는 `사용 불가` |
| 수치 | 스탯 변화량 (정수 또는 다이스 표기법: `ndm`, `ndm+k`, `-(ndm+k)`) |

---

## 아이템 분류

### 부피 기준 분류

| 부피 | 분류 | 저장 위치 |
|------|------|----------|
| 0 | 소형 아이템 | 여유공간 (자동) |
| 1~4 | 일반 아이템 | 가방 |
| 5+ | 대형 아이템 | 가방 |

### 사용 가능 여부

| 조건 | 사용 가능 |
|------|----------|
| 사용문구가 있음 | O |
| 사용문구가 공란 | X |
| 스탯이 `사용 불가` | X |

---

## 아이템 조회 함수

```python
def get_item_info(item_name: str) -> dict | None:
    """상점에서 아이템 정보 조회"""
    shop_ws = sheet.worksheet('상점')
    items = shop_ws.get_all_records()[1:]  # 2행 스킵

    for item in items:
        if item['아이템명'] == item_name:
            return {
                'name': item['아이템명'],
                'price': item['가격'],
                'description': item['설명'],
                'use_message': item['사용문구'],
                'stat': item['스탯'],
                'value': item['수치'],
                'volume': item['부피']
            }
    return None

def is_usable(item_info: dict) -> bool:
    """아이템 사용 가능 여부"""
    msg = item_info.get('use_message', '')
    return msg and msg != '-'

def is_misc_item(item_info: dict) -> bool:
    """부피 0 아이템 (여유공간) 여부"""
    return item_info.get('volume', 0) == 0
```
