# 1.1 - 데이터베이스 구조

## 개요

모든 데이터는 **Supabase PostgreSQL**에서 관리됩니다.

- **테이블**: `characters`, `items`
- **형식**: JSON 컬럼을 활용한 유연한 인벤토리 저장

---

## `characters` 테이블

캐릭터 정보와 인벤토리를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 | PK |
|------|------|------|:--:|
| name | text | 캐릭터 이름 | ✓ |
| id | text | 마스토돈 계정 ID (예: TP_Mst) | |
| side | text | 소속 진영 (웨가/스카이) | |
| con | integer | 체력 스탯 | |
| str | integer | 근력 (가방 용량 계산) | |
| luck | integer | 행운 스탯 | |
| hp | integer | 현재 HP | |
| points | integer | 소지금 (포인트) | |
| bag | jsonb | 가방 아이템 목록 | |
| misc | jsonb | 여유공간 아이템 목록 (부피 0) | |
| around | jsonb | 주변 아이템 (임시 보관) | |
| arrange | jsonb | 가방 그리드 배치 정보 | |

### 진영 정보

| 진영 | 설명 |
|------|------|
| 웨가 | 근력 사용 팀 |
| 스카이 | 근력 미사용 팀 |

### 아이템 저장 형식 (JSON)

`bag`, `misc`, `around` 컬럼은 JSON 객체로 아이템을 저장합니다.

```json
{
  "담배": 1,
  "바나나": 2,
  "반지": 1
}
```

### 배치 정보 형식 (JSON)

`arrange` 컬럼은 웹 그리드 UI의 아이템 배치 정보를 저장합니다.

```json
[
  {"name": "담배", "row": 0, "col": 0, "shapeIndex": 0},
  {"name": "바나나", "row": 1, "col": 2, "shapeIndex": 1}
]
```

### 데이터 예시

```sql
SELECT name, id, side, con, str, luck, hp, points, bag
FROM characters
LIMIT 3;
```

| name | id | side | con | str | luck | hp | points | bag |
|------|--------|------|-----|-----|------|-----|--------|-------------------------------------|
| 총괄 | TP_Mst | 웨가 | 103 | 5 | 80 | 1000 | 1000 | {"담배": 1, "바나나": 2, "반지": 1} |
| 스토리 | TP_Story | 스카이 | 100 | 10 | 50 | 900 | 500 | {"반지": 1, "사과": 3} |
| 발트 | TP_Balt | 스카이 | 14 | 13 | 1 | 140 | 200 | {} |

## `items` 테이블

아이템 마스터 정보를 관리합니다.

### 컬럼 구조

| 컬럼 | 타입 | 설명 | PK |
|------|------|------|:--:|
| name | text | 아이템 고유 이름 (**제한**: `/`, `,`, `:` 사용 불가) | ✓ |
| price | text | 구매 가격 (정수) 또는 `비매품` | |
| description | text | 아이템 설명 (`[설명/아이템명]` 명령어 시 출력) | |
| use_script | text | 사용 시 출력 메시지 (사용 불가 아이템은 공란) | |
| change_stats | text | 영향 받는 스탯 (체력, 근력, 행운) 또는 `사용 불가` | |
| change_value | text | 스탯 변화량 (정수 또는 다이스 표기법) | |
| size | integer | 차지하는 공간 (0 = 여유공간) | |

### 수치 필드 형식

`change_value` 필드는 다음 형식을 지원합니다:

| 형식 | 예시 | 설명 |
|------|------|------|
| 정수 | `10`, `-2` | 고정 수치 |
| 다이스 | `1d10` | n면체 주사위 m개 |
| 다이스+보정 | `1d6+3` | 주사위 + 고정값 |
| 다이스-보정 | `1d6-2` | 주사위 - 고정값 |
| 음수 다이스 | `-(1d6+3)` | 마이너스 효과 |

### 데이터 예시

```sql
SELECT name, price, description, use_script, change_stats, change_value, size
FROM items
LIMIT 5;
```

| name | price | description | use_script | change_stats | change_value | size |
|----------|-------|---------------------|--------------------------------------|--------------|--------------|------|
| 반지 | 70 | 노란색 보석이 박힌 은색 반지다. | 반지가 번쩍이며 정신이 말끔해진다. | 근력 | 10 | 0 |
| 사과 | 20 | 아삭아삭! | 달콤한 사과의 맛! | 체력 | 1d10 | 1 |
| 바나나 | 20 | 부드럽고 달콤하고... | 어라? 나... 바나나 알러지가 있었을지도? | 체력 | -2 | 2 |
| 아몬드 | 비매품 | 사실은 청산가리입니다. | 청산가리를 먹자 호흡이 가빠진다. | 체력 | -(1d6+3) | 0 |
| 파란 꽃병 | 50 | 꽃을 꽂아둘 수 있습니다. | | 사용 불가 | | 2 |

## 접근 방식

### Python (supabase-py)

```python
from supabase import create_client, Client

# Supabase 클라이언트 생성
supabase: Client = create_client(
    "https://your-project.supabase.co",
    "your_service_role_key"
)

# 캐릭터 전체 조회
response = supabase.table("characters").select("*").execute()
characters = response.data

# 이름으로 캐릭터 조회
response = (
    supabase.table("characters")
    .select("*")
    .eq("name", "총괄")
    .limit(1)
    .execute()
)
character = response.data[0] if response.data else None

# 마스토돈 ID로 캐릭터 조회
response = (
    supabase.table("characters")
    .select("*")
    .eq("id", "TP_Mst")
    .limit(1)
    .execute()
)

# 아이템 정보 조회
response = (
    supabase.table("items")
    .select("*")
    .eq("name", "사과")
    .limit(1)
    .execute()
)
item = response.data[0] if response.data else None

# 가방 아이템 업데이트
supabase.table("characters").update({
    "bag": {"사과": 5, "바나나": 2}
}).eq("name", "총괄").execute()
```
